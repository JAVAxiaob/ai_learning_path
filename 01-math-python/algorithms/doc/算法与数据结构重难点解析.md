## 一、复杂度分析 数学推导核心

### 1.1 主定理 Master Theorem 分治递归 (必考公式)

```
分治递归通式: T(n) = a T(n/b) + f(n)
  a = 子问题个数, n/b = 子问题规模, f(n) = 分解+合并的成本
三种情形比较 n^log_b(a)  vs  f(n):

Case 1: f(n) 多项式小于 → 叶子节点主导:
   若 f(n) = O(n^(log_b a - ε))  某ε>0
   → T(n) = Θ(n^log_b a)

Case 2: f(n) 多项式相等 → 每层贡献相等:
   若 f(n) = Θ(n^log_b a · log^k n)  k≥0
   → T(n) = Θ(n^log_b a · log^(k+1) n)

Case 3: f(n) 多项式大于 → 根节点主导:
   若 f(n) = Ω(n^(log_b a + ε)) 且正则条件 a·f(n/b) ≤ c·f(n), c<1
   → T(n) = Θ(f(n))
```

常考场景举例:
| 算法 | 递归式 | 主定理Case | 结果 |
|-----|-------|-----------|-----|
| 归并排序 | T(n)=2T(n/2)+Θ(n) | Case2 k=0 | Θ(n log n) ✔️ |
| 二分查找 | T(n)=T(n/2)+Θ(1) | Case2 k=0 log_b a=0 | Θ(log n) ✔️ |
| 朴素矩阵乘Strassen | T=7T(n/2)+Θ(n²) | Case1 | Θ(n^log7)=Θ(n^2.807) |

快排Partition模板 (Lomuto vs Hoare 双指针Hoare快2~3倍):
```python
def quicksort(arr, l, r):
    if l >= r: return
    pivot = arr[(l+r)//2]        # 选中间 避免有序数组最坏
    i, j = l, r
    while i <= j:
        while arr[i] < pivot: i += 1  # Hoare双指针左右扫
        while arr[j] > pivot: j -= 1
        if i <= j:
            arr[i], arr[j] = arr[j], arr[i]
            i += 1; j -= 1
    quicksort(arr, l, j); quicksort(arr, i, r)
```

## 三、二分查找 三大模板 + 边界处理

```python
# 模板1: 精确查找等于target (最基础)
def searchEqual(nums, target):
    l, r = 0, len(nums)-1
    while l <= r:
        mid = (l + r) // 2         # 偶数个时取左中
        if   nums[mid] < target: l = mid + 1  # 太小 往右找
        elif nums[mid] > target: r = mid - 1  # 太大 往左找
        else: return mid                     # 命中!
    return -1

# 模板2: 第一个>=target (下界lower_bound 必考⭐)
def lowerBound(nums, target):
    l, r = 0, len(nums)                    # 注意r=n开区间
    while l < r:
        mid = (l + r) // 2
        if nums[mid] < target: l = mid + 1  # 不满足 往右
        else: r = mid                       # 满足 继续往左收!
    return l  # 返回插入位置 也是第一个>=target的索引

# 模板3: 第一个>target (上界upper_bound)
def upperBound(nums, target):
    l, r = 0, len(nums)
    while l < r:
        mid = (l + r) // 2
        if nums[mid] <= target: l = mid + 1 # 注意<=区别!
        else: r = mid
    return l
# target出现次数 = upperBound - lowerBound  ✔️ O(logn)求频次
```

### 4.1 快慢双指针 5大用法
```python
# ① 找中点: 快走2步 慢走1步 快到尾慢在中点
def findMiddle(head):
    s=f=head
    while f and f.next:
        s=s.next; f=f.next.next
    return s

# ② 判环 Floyd龟兔: 相遇=有环 再head→相遇点各走1步=入口点⭐
def detectCycle(head):
    s=f=head
    while f and f.next:
        s=s.next; f=f.next.next
        if s is f:           # 有环!
            while head is not s:
                head=head.next; s=s.next
            return s        # 返回环入口
    return None

# ③ 找倒数第k个: 快先走k步 然后同速 快停时慢=倒数k
# ④ 环长: 相遇后继续走 再相遇时慢走步数=周长
# ⑤ 有序链表合并: k个升序用最小堆O(Nlogk)归并
```

## 五、二叉树遍历 5种必考写法

```python
# ① 前序Pre 根-左-右 (迭代栈)
def preorder(root):
    res, stack = [], [root]
    while stack:
        n = stack.pop()
        if n:
            res.append(n.val)
            stack.extend([n.right, n.left])  # 右先压 后进先出!
    return res

# ② 中序In 左-根-右 ⭐BST升序 迭代通用模板
def inorder(root):
    res, stack, cur = [], [], root
    while stack or cur:
        while cur:
            stack.append(cur); cur = cur.left  # 一路往左钻
        cur = stack.pop()
        res.append(cur.val)                    # 根
        cur = cur.right                        # 处理右子树
    return res

# ③ 后序Post 左-右-根 = 根-右-左 反转 (技巧!)
def postorder(root):
    res, s = [], [root]
    while s:
        n = s.pop()
        if n:
            res.append(n.val)
            s.extend([n.left, n.right])  # 前序基础上L/R交换
    return res[::-1]                       # ✔️ 最后反转!

# ④ BFS层序 Level 队列deque
from collections import deque
def levelOrder(root):
    if not root: return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):  # 每一层数量 批处理⭐
            n = q.popleft()
            level.append(n.val)
            if n.left:  q.append(n.left)
            if n.right: q.append(n.right)
        res.append(level)
    return res

# ⑤ 递归统一模板: helper函数 + 非局部变量self.res存结果
```

Dijkstra 邻接表+堆标准模板:
```python
import heapq
def dijkstra(n, edges, src):
    graph = [[] for _ in range(n)]
    for u, v, w in edges:
        graph[u].append((v, w))
    dist = [float('inf')] * n
    dist[src] = 0
    pq = [(0, src)]  # (距离, 节点) 小根堆
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue  # 旧记录 跳过⭐避免重复处理
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```
