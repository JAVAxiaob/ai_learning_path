### 2.2 二分查找万能模板 (LeetCode 通用)

```python
def binary_search_template(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2    # 防溢出: left + (right-left)//2
        if arr[mid] == target:
            return mid              # 命中
        elif arr[mid] < target:
            left = mid + 1          # 搜索右半区
        else:
            right = mid - 1         # 搜索左半区
    return -1  # 没找到: right是<target的右边界, left是>target的左边界
```

## 四、高频面试题 (大厂常考)

**Q: Top-K 大数据问题怎么解？**
> A: 三档方案：① 最小堆 O(nlogK) 流式/内存友好 ② 快速排序分区思路 平均O(n)最坏O(n²) ③ BFPRT算法 严格O(n)但常数大。工程选①堆：10亿数据找Top100只用维护100个元素的小根堆，内存几KB搞定。

**Q: LRU缓存怎么实现？复杂度O(1)**
> A: 双向链表 + 哈希表。哈希表存 key→Node 实现O(1)查找；双向链表维护最近使用顺序，头=最近用，尾=最久没用。
> get(key): hash表找→移到链表头→返回value
> put(key,value): 存在则更新+移头；不存在→满了先删尾节点再插入头；全程维护哈希表映射。

**Q: 动态规划6步法 + 01背包公式？**
> A: 6步：①确定dp数组含义 ②递推公式 ③初始化 ④遍历顺序(正序倒序！) ⑤举例推导 ⑥Debug打印dp。01背包：`dp[j] = max(dp[j], dp[j-weight[i]]+value[i])` 一维数组j必须倒序遍历避免重复取；完全背包j正序(每件无限取)。
