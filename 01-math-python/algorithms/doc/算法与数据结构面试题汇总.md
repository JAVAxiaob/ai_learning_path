### Q1. 主定理 Master Theorem 三情形分别举例（⭐⭐⭐）

**【标准答案】**

#### 1. 主定理适用范围
**分治递归式标准形**：`T(n) = a·T(n/b) + f(n)`
- `a`：子问题个数（≥1）
- `b`：子问题规模缩小因子（>1）
- `f(n)`：分治+合并的工作量

#### 2. 核心量 `n^log_b a` 叫「递归树叶子节点工作量」
比较 `f(n)` 和 `n^log_b a` 的多项式级增长关系，三情形：

| 情形 | 条件（比较量级） | 解 T(n)= | 面试高频举例 |
|-----|----------------|---------|-------------|
| **Case 1 叶子多活少** | f(n) 多项式更小，`f(n) = O(n^(log_ba - ε)), ε>0` | **Θ(n^log_b a)** | 二分不行，例：Strassen矩阵乘法 T=7T(n/2)+n² → n^log₂7≈n².8 比n²大 → Case1 |
| **⭐ Case 2 同量级** | f(n) 同阶，`f(n) = Θ(n^log_b a · log^k n), k≥0` | **Θ(n^log_b a · log^(k+1) n)** | ①**归并排序** T=2T(n/2)+n → a=2,b=2 → n^1 = f(n)=n k=0 → Θ(n log n)<br>②Karatsuba乘法可以归但通常不考 |
| **Case 3 活多叶子少** | f(n) 多项式更大，`f(n) = Ω(n^(log_ba + ε))` + 正则条件a·f(n/b) ≤ c·f(n) | **Θ(f(n))** | 例：T(n) = 2T(n/2) + n³ → n^1 << n³ → Θ(n³) |

> **⚠️ 二分查找为什么单独写？**
>
> 二分：`T(n) = T(n/2) + 1`，a=1,b=2 → n^log₂1 = n⁰ = 1，刚好等于 f(n)=1 → **Case2** k=0 → Θ(1·log^(0+1)n) = **Θ(log n)** ✅

#### 3. 面试追问
- Q：主定理能解所有递推吗？A：不行。像 `T(n) = 2T(n/2) + n log n` 虽然可以用扩展Case2，但 `T(n) = T(n-1) + n`（插入排序）这种线性递归就用不了，要用累加展开法。

### Q2. 九大排序时空稳定性对比表（⭐⭐⭐⭐⭐ 必背默写级）

**【标准答案】**

> **稳定性定义**：相等大小的元素排序后，**原数组中相对位置不变**。例：`[2a, 2b, 1]` 稳定排序后一定是 `[1, 2a, 2b]`，不会 `2b` 跑 `2a` 前面。业务中对Object按年龄排、同年龄要保持按姓名字典序就必须稳定。

| 排序算法 | 平均 T | 最坏 T | 最好 T | 空间 S | 是否稳定 | 原地 | 面试必记场景/备注 |
|---------|-------|-------|-------|-------|---------|-----|-----------------|
| ⚪ 冒泡排序 Bubble | n² | n² | **n**（加swap标志提前break优化版） | 1 | ✅ 稳定 | ✅ 原地 | 教学用，**100%不写生产** |
| ⚪ 选择排序 Select | n² | n² | n² | 1 | ❌ 不稳定 | ✅ 原地 | 交换次数最少n-1次，但慢 |
| ⚪ 插入排序 Insert | n² | n² | **n**（已排序） | 1 | ✅ 稳定 | ✅ 原地 | **小数据量/<32元素首选**，TimSort底层混它 |
| 🟢 **希尔排序 Shell** | n^1.3 | n² | - | 1 | ❌ 不稳定 | ✅ 原地 | 插入排序升级版跳步，**不考代码只考名字+不稳** |
| 🔴 **快速排序 Quick** | nlogn | **n²**（逆序+选首pivot） | nlogn | logn栈 | ❌ 不稳定 | ✅ 原地 | ⭐**生产默认最快**，缓存命中率高 |
| 🔵 **归并排序 Merge** | nlogn | nlogn | nlogn | **n** 额外数组 | ✅ **稳定** | ❌ 额外n | ⭐**唯一稳定nlogn排序**，大数据外排序/链表排序 |
| 🟡 **堆排序 Heap** | nlogn | nlogn | nlogn | 1 | ❌ 不稳定 | ✅ 原地 | TopK问题必用，常数比快排大2-3倍 |
| ⚫ 计数排序 Count | n+K | n+K | n+K | K | ✅ 稳定 | ❌ | **非比较**，K范围小的整数，如分数0-100 |
| ⚫ 桶排序 Bucket | n+K | n² | n | n+K | ✅ 稳定 | ❌ | 非比较，数据均匀分布 [0,1]浮点数 |
| ⚫ 基数排序 Radix | d(n+r) | - | - | n+r | ✅ 稳定 | ❌ | 非比较，按位排，手机号/身份证/长整数 |

#### 面试追问速答
- Q：Arrays.sort / sort包用什么？
  A：Java/JDK8 基本类型用**双轴快排DualPivotQuicksort**（不用稳，基本类型==就等价）；Object[]用**TimSort**（归并+插入混合，**稳定**，Python3/ES/Go默认同款）。
- Q：快排不稳举例子？A：`[2a, 2b, 1]` 首元素2a做pivot，最后小于pivot的1和pivot交换 → `[1,2b,2a]`，两个2交换了位置 → 不稳。
- Q：堆排不稳举例子？A：`[2a,1,2b]` 先建大顶堆取出第一个2a放末尾；接着堆化剩余`[2b,1]`，交换取2b放到倒数第二 → 最终`[1,2b,2a]`，两个2顺序反了。

### Q3. 快排最坏O(n²)为什么还是生产默认？（⭐⭐⭐⭐）

**【标准答案】**

4大原因按重要性：

1. **最坏情况概率极低，现代优化基本消除**
   - 真正最坏 = 每次选pivot是全局最小/最大（如已升序数组每次选首元素），概率 `1/n!` 天文数字。
   - **三道防线**：①随机选pivot / ②三数取中（首中尾三个数取中位数做pivot，已排序数组直接拿中间数完美）/ ③三路快排（荷兰国旗分 < = > 三段，重复元素多的场景避免退化）→ 生产实测从未见过n²。

2. **常数因子最小（最关键原因）**
   - 同是nlogn，快排常数≈2，堆排序常数≈5-8，归并≈4。
   - 数学上O()忽略系数，但**实际运行时间快排比堆排快2-3倍**。

3. **缓存命中率最高**
   - 快排是**原地排序**，分区时操作的元素在内存中连续，顺序访问CPU L1/L2缓存命中率极高。
   - 对比：归并要开新数组跳来跳去、堆排序父子节点索引差一半（i和2i），内存跳跃大缓存miss多。

4. **生态成熟，库实现极度优化**
   - JDK/STL都是经过几十年工程迭代的双轴快排DualPivotQuickSort：小数组切插入排序、五数取样、尾递归消除栈深logn。

> 💡 面试加分答：**什么时候不用快排用归并？**
> - 需要稳定排序（业务有重复key保序需求）
> - 链表排序（链表归并不用额外S，指针改一下就行O(1)空间）
> - 大数据外排序磁盘上（快排随机IO性能差，归并适合顺序读写）

### Q4. 小顶堆/大顶堆上浮下沉；TopK为什么小顶堆K个不是大顶堆？（⭐⭐⭐⭐⭐）

**【标准答案】**

#### 1. 堆基础定义
- **堆**：完全二叉树 + 父≤子（小顶堆MinHeap）或 父≥子（大顶堆MaxHeap）的性质
- **数组存堆的索引**（0基）：
  ```
  父节点 i  → 左孩子 = 2i+1, 右孩子 = 2i+2
  孩子 j    → 父节点 = (j-1)//2
  ```

#### 2. 上浮（插入新元素用）+ 下沉（删堆顶用）代码

```python
class MinHeap:
    def __init__(self): self.h = []

    # ========== 上浮 O(log n)：刚加的元素放末尾，一路和父比，比父小就换 ==========
    def _sift_up(self, i):
        while i > 0:                    # 没到根
            parent = (i - 1) // 2
            if self.h[i] < self.h[parent]:  # 比父小 → 违背小顶堆 → 往上爬
                self.h[i], self.h[parent] = self.h[parent], self.h[i]
                i = parent
            else: break

    # ========== 下沉 O(log n)：堆顶和最后一个换，新根一路和两孩子小的换 ==========
    def _sift_down(self, i):
        n = len(self.h)
        while True:
            l, r = 2*i+1, 2*i+2
            smallest = i
            if l < n and self.h[l] < self.h[smallest]: smallest = l
            if r < n and self.h[r] < self.h[smallest]: smallest = r
            if smallest == i: break      # 三个位置父最小 → 到位了
            self.h[i], self.h[smallest] = self.h[smallest], self.h[i]
            i = smallest

    def push(self, x):
        self.h.append(x); self._sift_up(len(self.h)-1)
    def pop(self):
        top = self.h[0]
        self.h[0] = self.h[-1]
        self.h.pop()
        if self.h: self._sift_down(0)
        return top
    def top(self): return self.h[0]
    def __len__(self): return len(self.h)
```

#### 3. 🔥 TopK问题经典面试追问：找**前K大**的数，为什么用**小顶堆大小K**，不用大顶堆大小N？

| 方案 | 数据结构 | 时间复杂度 | 空间复杂度 | 是否大数据流可用 | 原理 |
|-----|---------|-----------|-----------|---------------|------|
| ✅ **小顶堆K个（正确）** | 维护当前TopK的**小顶堆**（堆顶是K个里**最小的那个守门员**） | **O(n log k)** | **O(k)** 极小 | ✅ 流式无限数据一边进一边扫 | 新来的数 > 堆顶(当前第K大) → 把堆顶踢掉换新 → 扫描完堆里就是全局TopK |
| ❌ 大顶堆全量N个 | 所有数丢大顶堆，pop K次 | O(n log n) | **O(n)** 大（100亿数据直接爆内存） | ❌ 存不下 | 简单但在大数据/面试场景**直接挂**，空间和时间都输 |

```python
import heapq  # Python heapq 默认就是小顶堆！ 大顶堆 = push(-x)
def top_k_largest(nums, k):
    heap = []
    for num in nums:
        if len(heap) < k:
            heapq.heappush(heap, num)
        elif num > heap[0]:  # 比守门员大 → 挤进去
            heapq.heapreplace(heap, num)
    return heap  # 返回的是TopK，第K大的在堆[0]
```

> 面试追问：那求**第K小**的数呢？反过来，用**大顶堆存K个**，堆顶是K个里最大的；新来的 < 堆顶就替换。或者反过来，小顶堆N个popK次都可以，逻辑对称别搞反。

#### 三大非比较排序对比

> ✅ 但踩对了场景：比如学生分数，计数排序 O(n+750) ≈ O(n) 秒掉任何nlogn排序，差了logn倍！

### Q6. 二分查找三大模板 lower_bound/upper_bound/精确查（⭐⭐⭐⭐⭐ 100%必考手写）

**【标准答案】**

#### 1. 先背「左闭右开[l, r)」一套通所有，不要再死记两套开闭
> 记忆口诀：while (l < r) → mid = (l + r) // 2 → 满足条件的往哪边靠，就 `r = mid` 或 `l = mid + 1`，**永远不会死循环**（+1错开）

```python
# ============== 模板1：精确查找 target 有就返回index，没就-1 ==============
def binary_search_exact(nums, target):
    l, r = 0, len(nums)               # [l, r) 左闭右开
    while l < r:                      # 区间空了就停
        mid = (l + r) // 2
        if   nums[mid] == target: return mid   # 找到了
        elif nums[mid] <  target: l = mid + 1 # 肯定不包含mid, 所以l跳过mid
        else                      : r = mid     # 可能包含mid, r不动
    return -1                         # 没找到

# ============== 模板2：lower_bound 第一个 >= target 的下标（有重复的左边界） ==============
def lower_bound(nums, target):
    l, r = 0, len(nums)
    while l < r:
        mid = (l + r) // 2
        if nums[mid] >= target: r = mid      # 满足条件(>=)：往左找更早的，但mid本身可能是答案 → r=mid
        else                  : l = mid + 1  # 不满足：往右
    return l  # 找不到就返回插入位置，==len(nums)说明所有数都<target

# ============== 模板3：upper_bound 第一个 > target 的下标（有重复的右边界） ==============
def upper_bound(nums, target):
    l, r = 0, len(nums)
    while l < r:
        mid = (l + r) // 2
        if nums[mid] > target: r = mid       # ✅ 唯一区别：把 >= 改成 >
        else                : l = mid + 1
    return l

# ===== 测试 =====
arr = [1,3,3,3,5,7,7,9]  # 有重复的3和7
print(lower_bound(arr, 3))  # =1  第一个3
print(upper_bound(arr, 3))  # =4  第一个>3的5
# 💡 所以 target=3 的出现次数 = upper - lower = 4-1 = 3次！（经典O(logn)重复计数面试题）
print(binary_search_exact(arr, 7))  # =5或6都行，精确查只要存在返回一个就行
```

#### 2. 面试追问高频变形
- Q：求排序数组中target出现次数？A：`upper_bound - lower_bound`，O(logn)，别一个个数。
- Q：在旋转数组找最小值？（Leet 153）A：模板变形，比较`nums[mid]`和`nums[r]`分左右半有序。
- Q：二分答案（最小化最大值 / 最大化最小值）？A：最常考的二分答案套法，核心是写`check(mid)能不能满足`，然后套lower/upper套模板。

### Q7. 快慢双指针 Floyd龟兔判环 + 环入口 + 5种应用（⭐⭐⭐⭐⭐）

**【标准答案】**

#### 1. 核心设定
- 慢指针 `slow` 每次走 **1步**，快指针 `fast` 每次走 **2步**（或3步，但2步最常用保证相遇）
- 有环 → fast必然绕圈最后追上slow（套圈）；无环 → fast必然先跑到tail.next = None

```python
class ListNode:
    def __init__(self, x, next=None): self.val = x; self.next = next

# ============== 判环（Leet141） ==============
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:          # fast快，先判断它别越界
        slow = slow.next
        fast = fast.next.next
        if slow is fast: return True
    return False

# ============== 🔥 环入口节点（Leet142，最常考公式推导） ==============
def detect_cycle_entry(head):
    slow = fast = head
    # Phase 1: 找相遇点
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast: break
    else:        # while正常走完没break = 没环
        return None
    # Phase 2: fast回到head，双指针都每次走1步，再次相遇 = 入口点
    fast = head
    while fast is not slow:
        slow = slow.next
        fast = fast.next
    return fast  # 或slow，完全等价
```

#### 2. 📐 环入口公式为什么是对的？（必须背推导，阿里美团常让白板推）
```
     a段        环长 = b + c
 ○───────●━━━━━━━━━┓
         ↑入口  b   ↓相遇点
         ┗━━━c━━━━━┛
```
设：head → 入口的直线段长 = `a`；入口顺时针 → 相遇点长 = `b`；相遇点再顺时针 → 入口长 = `c`（所以环长 `L = b + c`）

相遇时：
- slow走的：`a + b`
- fast走的：`a + b + k·L`（套了k圈）
- 又 fast = 2·slow → `a + b + kL = 2(a + b)` → `a = kL - b = (k-1)L + c`

✅ 特别k=1时 **a = c**！这就是为什么fast放回头走a步、slow从相遇点绕c步，会刚好在入口相遇。a=c几何意义：相遇点到入口的距离 = 头到入口距离。

#### 3. 快慢指针5大经典应用总结表
| 应用 | 做法 | 复杂度 |
|-----|------|-------|
| ① 单链表找中点（归并排序、回文判断） | fast到末尾时slow刚到一半；偶数长度slow是前半最后一个 | O(n) |
| ② 判环 + 找环入口 | 上面两段代码 | O(n) |
| ③ 找**倒数第k个**节点（更常用双指针间隔k，不一定快慢） | p1先走k步，然后p1p2同速走，p1到尾p2就是倒数k | O(n) |
| ④ 删除有序链表重复元素（快指针探路，不一样慢指针才接） | slow=head fast=head.next; while fast: val不等slow.next=fast; 最后slow.next=None断多余 | O(n) |
| ⑤ 快乐数（Leet202 算平方和会不会循环到1） | 把每次的平方和结果当链表节点值，有环就不会到1 | O(logn) |

### Q8. 相向左右双指针：两数之和有序版 / 三数之和 / 盛水 / 接雨水（⭐⭐⭐⭐⭐）

**【标准答案】**

> 共同点：排序好的数组 / 有单调性 → 左右两指针从两端往中间夹，把**O(n²)暴力缩到O(n)**

```python
# ============== ①两数之和II 输入已排序 （Leet167） ==============
def two_sum_sorted(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if   s == target: return [l+1, r+1]  # 题要求1基下标
        elif s <  target: l += 1  # 不够大，左指针右移加加
        else            : r -= 1  # 太大了，右指针左移减减
    return []

# ============== ②盛最多水的容器 （Leet11，图解：两根柱子中间接水面积） ==============

def max_area(height):
    ans, l, r = 0, 0, len(height) - 1
    while l < r:
        area = min(height[l], height[r]) * (r - l)
        ans = max(ans, area)
        if height[l] < height[r]: l += 1  # ✅ 关键：只移动短的那根！（移长的面积必然更小，剪枝）
        else                    : r -= 1
    return ans

# ============== ③三数之和=0 + 去重（Leet15，90%公司考） ==============
def three_sum(nums):
    nums.sort()              # 1. 先排序 O(n logn)
    n, ans = len(nums), []
    for i in range(n - 2):
        if nums[i] > 0: break                       # 剪枝：第一个数>0，三数和必>0
        if i > 0 and nums[i] == nums[i-1]: continue  # 🔴 去重i：相同首元素必重复
        # 下面就是 two_sum_sorted 左右双指针
        l, r, t = i+1, n-1, -nums[i]
        while l < r:
            s = nums[l] + nums[r]
            if   s == t:
                ans.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l+1]: l += 1  # 🔴 去重l
                while l < r and nums[r] == nums[r-1]: r -= 1  # 🔴 去重r
                l += 1; r -= 1
            elif s < t: l += 1
            else      : r -= 1
    return ans
```

```python
    for ch in t: need[ch] += 1
    left = right = valid = 0          # valid：满足need条件的字符种数

            d = s[left]; left += 1
            if d in need:
                if window[d] == need[d]: valid -= 1  # 去掉后刚好不够了
                window[d] -= 1
    return '' if min_len == float('inf') else s[start:start+min_len]
```

### Q10. 前缀和 + 哈希表：和为K的子数组个数（⭐⭐⭐⭐⭐）

**【标准答案】**

#### 1. 为什么不能用滑动窗口？
滑动窗口能用的前提是 **单调性 + 全正数**（右扩和单调变大，左缩和单调变小）。
> 🔴 本题数组里**有负数** → 右加一个元素总和可能变小 → 单调性没了 → 滑动窗口全错。
> 所以必须用 `前缀和 + HashMap计数` O(n)。

```python
# 和为 K 的子数组个数（Leet 560，90%公司考）
from collections import defaultdict
def subarray_sum_equals_k(nums, k):
    prefix_cnt = defaultdict(int)
    prefix_cnt[0] = 1           # ⭐ 哨兵：前缀和=0的出现了1次（空前缀，对应子数组从0开始的情况）
    cur_sum = ans = 0
    for num in nums:
        cur_sum += num          # cur_sum = 前缀和[0..当前]
        # 核心：当前前缀和S，要找之前有多少个前缀和 = S-K
        #       因为 [i..j] 和 = prefix[j] - prefix[i-1] = K → prefix[i-1] = prefix[j]-K
        if (cur_sum - k) in prefix_cnt:
            ans += prefix_cnt[cur_sum - k]
        prefix_cnt[cur_sum] += 1  # 最后再把当前前缀和加进去，避免包含自己
    return ans

# ======= 测试 =======
print(subarray_sum_equals_k([1,2,3,-3,3], 3))

```

### Q11. 差分数组：区间加值 + 航班订票 / 拼车（⭐⭐⭐⭐）

**【标准答案】**

#### 1. 差分数组定义（O(1)加区间 + O(n)还原原数组）
原数组 `A[0..n-1]`，差分数组 `diff[0..n]`（长度n+2 避免越界）：
```
diff[i]     = A[i] - A[i-1]        # diff是相邻差，d[0]=A[0]
---
要对 A[l..r] 全加 val：只改两处 O(1) 不用循环l到r！
  ✅ diff[l]     += val
  ✅ diff[r + 1] -= val
---
最后求原数组 A：从左到右 前缀和 累加diff → A[i] = prefix_sum(diff[0..i])
```

```python
# ========== 航班预订统计 (Leet 1109 官方原描述) ==========
# 有n个航班，1..n；每条预订 bookings[i]=[firsti, lasti, seatsi]：first到last航班各加seats座位
# 返回n个航班最终座位数
def corp_flight_bookings(bookings, n):
    diff = [0] * (n + 2)             # 0和n+1是哨兵位 1基
    for first, last, val in bookings:
        diff[first]     += val
        diff[last + 1]  -= val
    # 前缀和还原
    ans = [0] * n
    cur = 0
    for i in range(1, n + 1):
        cur += diff[i]
        ans[i-1] = cur
    return ans

# ========== 拼车 (Leet 1094 能否装下capacity) ==========
# trips[i]=[num, from, to] 上车from人num, 下车to人num；capacity=车最大人数 能不能完成行程
def car_pooling(trips, capacity):
    diff = [0] * 1002                # 题目说to<=1000
    for num, frm, to in trips:
        diff[frm] += num
        diff[to]  -= num             # to这个站下车，所以to开始人没了 不用to+1
    cur = 0
    for i in range(1001):
        cur += diff[i]
        if cur > capacity: return False
    return True
```

> 适用场景总结：所有「**批量区间加值→最后求最终状态**」的题，暴力O(n·k)超时，差分O(n+k)秒杀。常见：区间加一个数/区间乘/区间赋值，以及上面的加减乘客、座位统计、日程安排重叠数等。

### Q12. Dummy虚拟头节点 + 三指针法：翻转链表 / 两两交换 / K个一组翻转（⭐⭐⭐⭐⭐）

```python
def reverse_list(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next      # ⭐三指针：先保下一个！别丢了
        curr.next = prev     # 指向翻过来
        prev = curr          # prev前进
        curr = nxt           # curr前进
    return prev

# ============== ② 两两交换相邻节点（Leet 24） dummy + 每两个翻一次 ==============
def swap_pairs(head):
    dummy = ListNode(0, head)
    pre = dummy                         # pre = 要翻转的**两个节点的前驱**
    while pre.next and pre.next.next:   # 还有两个才能翻
        a, b = pre.next, pre.next.next  # 要翻的两个
        # 三步走画图记住：pre→a→b→c  变成 pre→b→a→c
        pre.next = b; a.next = b.next; b.next = a
        pre = a                         # 移到下一组的前驱=a
    return dummy.next

# ============== ③ ⭐K个一组翻转（Leet 25 字节腾讯Top50常考） ==============
def reverse_k_group(head, k):
    dummy = ListNode(0, head)
    pre_group_end = dummy               # 上一组的尾节点（固定）
    while True:
        # 先走到这组的尾结点 end，不够k个直接结束
        end = pre_group_end
        for _ in range(k):
            end = end.next
            if not end: return dummy.next
        start = pre_group_end.next      # 这组头
        next_group_start = end.next     # 下一组头（保存）
        end.next = None                 # 切断 → 单独翻start~end
        pre_group_end.next = reverse_list(start)  # 翻完接到上一组
        start.next = next_group_start   # 翻完的尾巴(start变尾了)接下一组头
        pre_group_end = start           # 前进到本组尾=下一组前驱
```

### Q13. 链表相交节点（⭐⭐⭐⭐ 数学浪漫题：你变成我我变成你，就能相遇）

**【标准答案】**

```
A:      a1→a2
              ↘
               c1→c2→c3  (公共尾巴长度=c)
              ↗
B: b1→b2→b3
长度A = a + c, 长度B = b + c
```

#### 🔥 秒杀解法 双指针浪漫公式：`A+B = B+A`
p1走A → 走完A换B头走；p2走B → 走完B换A头走。**同速每步1，必然在交点相遇！** （数学：走了a+b+c步，刚好在交点停下）

```python
def get_intersection_node(headA, headB):
    p1, p2 = headA, headB
    # while循环条件：两个指针没相遇就一直走；p1/p2走到尾None会切另一边；没交点最后都到None==None退出
    while p1 is not p2:
        p1 = p1.next if p1 else headB  # 走完A切到B头
        p2 = p2.next if p2 else headA  # 走完B切到A头
    return p1  # 有交集返回节点；没交集返回None，因为最后都变None==None
```

> 面试追问：不能用HashMap存所有A节点吗？A：可以，但HashMap S=O(n)；上面双指针S=O(1) T=O(n)是最优。

### Q14. LRU缓存设计 哈希表+双向链表（⭐⭐⭐⭐⭐ 阿里/字节100%必考题）

**【标准答案】**

> LRU = Least Recently Used 最近最少使用。get/put都必须O(1)。
> 数据结构组合：**HashMap(key→Node)** O(1)查；**双向链表** O(1)插/删 维护最近使用顺序：
> - 链表头 = 最近刚用过的（热）
> - 链表尾 = 最久没用的（冷）→ 容量满时删tail
> - get(key) 命中 → 把对应node从原位置删、**插到链表头**
> - put(key) 新加入 → 插头部；容量超 → 删tail + HashMap同步删key

```python
# =========== 双向链表节点 ===========
class DLinkedNode:
    def __init__(self, key=0, val=0):
        self.key = key   # ⚠️ node里要存key！删tail时才能找HashMap的key删
        self.val = val
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}               # key → DLinkedNode
        # dummy head/tail 头尾哨兵 插删不用判空
        self.head, self.tail = DLinkedNode(), DLinkedNode()
        self.head.next = self.tail
        self.tail.prev = self.head

    # ---------- 2个辅助链表操作 O(1) ----------
    def _add_to_head(self, node):    # 刚用的插到head后面第一位
        node.prev = self.head; node.next = self.head.next
        self.head.next.prev = node; self.head.next = node
    def _remove(self, node):         # 任意位置删
        node.prev.next = node.next; node.next.prev = node.prev
    def _move_to_head(self, node):   # 命中 → 先删原位置 → 再插head
        self._remove(node); self._add_to_head(node)
    def _pop_tail(self):             # 删最久没用的 并返回它（删hashmap要用key）
        node = self.tail.prev; self._remove(node); return node

    # ---------- 对外API ----------
    def get(self, key: int) -> int:
        if key not in self.cache: return -1
        node = self.cache[key]; self._move_to_head(node)   # ⭐核心：用了挪到最前
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:                              # 更新已有
            node = self.cache[key]; node.val = value; self._move_to_head(node)
        else:                                               # 新增
            node = DLinkedNode(key, value); self.cache[key] = node; self._add_to_head(node)
            if len(self.cache) > self.cap:                  # ⚠️ 超容量：删tail！
                removed = self._pop_tail(); del self.cache[removed.key]

# ========= Python OrderedDict 作弊一行版（面试加分项 但一定要会手写双向链表）=========
from collections import OrderedDict
class LRUCacheShort:
    def __init__(self, cap): self.cap, self.d = cap, OrderedDict()
    def get(self, k): return (self.d.move_to_end(k) or self.d[k]) if k in self.d else -1
    def put(self, k, v):
        if k in self.d: self.d.move_to_end(k)
        self.d[k] = v
        if len(self.d) > self.cap: self.d.popitem(last=False)  # 删最左最早的
```

### Q15. 合并K个升序链表（⭐⭐⭐⭐）

**【标准答案】**

```python
import heapq
from typing import List, Optional
class ListNode:
    def __init__(self, x=0, nxt=None): self.val, self.next = x, nxt

# ========== 方案A：最小堆 O(N log k) 生产常用 ==========
def merge_k_lists_heap(lists: List[Optional[ListNode]]):
    heap = []
    for i, node in enumerate(lists):  # 每个链表的头先入堆
        if node:
            heapq.heappush(heap, (node.val, i, node))  # ⚠️ i的作用：同val时比i避免Node比大小报错
    dummy = p = ListNode(0)
    while heap:
        val, i, node = heapq.heappop(heap)
        p.next = node; p = p.next
        if node.next:  # 下一个节点入堆
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next

# ========== 方案B：分治法两两归并 O(N log k) k路归并外排序 ==========
def merge_two(l1, l2):  # 合并两个有序链表 基础中的基础
    d = p = ListNode(0)
    while l1 and l2:
        if l1.val < l2.val: p.next, l1 = l1, l1.next
        else              : p.next, l2 = l2, l2.next
        p = p.next
    p.next = l1 if l1 else l2
    return d.next

def merge_k_lists_divide(lists: List[Optional[ListNode]], l=0, r=None):
    if r is None: r = len(lists) - 1
    if l > r: return None
    if l == r: return lists[l]
    mid = (l + r) // 2
    left  = merge_k_lists_divide(lists, l, mid)
    right = merge_k_lists_divide(lists, mid+1, r)
    return merge_two(left, right)
```

> 堆的坑：如果两个链表头val相同，Python heapq会拿Node比大小，Node对象没有`__lt__`会抛TypeError。所以入堆元组加`(val, 链表下标i, node)`，同val比整数i就不会报错。面试要主动提这个坑才能拿满分。

#### 方案A：HashMap映射法 好记 O(n) O(n) 90%写这个就行
```python
def copy_random_list(head):
    if not head: return None
    mp = {}                         # 原Node → 新Node
    p = head
    while p:                        # 第一步：复制所有节点值，建立映射
        mp[p] = Node(p.val); p = p.next
    p = head
    while p:                        # 第二步：利用映射填next和random
```

#### 方案B：🔥 插中间法 空间O(1) 面试加分版 （3步）
```
原链:      1 → 2 → 3 → None
Step1 每个节点后面插自己的拷贝:
           1 → 1'→ 2 → 2'→ 3 → 3'→ None
Step2 新节点的random = 原节点.random的下一个（因为random是原节点，后面跟的就是它的copy）
           1'.random = 1.random.next
Step3 把两条链拆开，奇偶位分别串起来
```

```python
def copy_random_list_O1(head):
    if not head: return None
    # 1. 插入copy 奇=原 偶=副本
    p = head
    while p:
        p.next = Node(p.val, p.next, None); p = p.next.next
    # 2. 填random
    p = head
    while p:
        if p.random: p.next.random = p.random.next
        p = p.next.next
    # 3. 拆链
    dummy = p2 = Node(0); p = head
    while p:
        p2.next = p.next; p2 = p2.next
        p.next = p.next.next; p = p.next
    return dummy.next
```

#### 1. 递归DFS（写最快，面试先写这个打底）
```python
def preorder_recur(root):
    return [root.val] + preorder_recur(root.left) + preorder_recur(root.right) if root else []
```

#### 2. 🔥 迭代栈「颜色标记法」**统一三序模板**（一个模板改顺序秒杀所有遍历，字节推荐）
> 白节点=未访问过入栈时标记灰，灰节点=访问输出。三序唯一差别：**栈里塞三个节点的顺序**（栈LIFO所以要反过来）
```python
# 颜色标记：节点=白（未处理），值=灰（可直接输出）
# ========= 前序：根 左 右 → 入栈 【右, 左, 根】（反的，因为栈后入先出） =========
def preorder_iter_universal(root):
    res, stack = [], [root]
    while stack:
        cur = stack.pop()
        if cur is None: continue
        if isinstance(cur, int): res.append(cur)   # 灰：已准备好直接加
        else:  # 白：是TreeNode → 展开塞回去  👉 顺序唯一改这里 👈
            stack.extend([cur.right, cur.left, cur.val])  # ⚠️前序放最后/最上=最先出
    return res

# ========= 中序：左 根 右 → 入栈 【右, 根, 左】 =========
def inorder_iter_universal(root):
    res, stack = [], [root]
    while stack:
        cur = stack.pop()
        if cur is None: continue
        if isinstance(cur, int): res.append(cur)
        else:
            stack.extend([cur.right, cur.val, cur.left])  # ⚠️ val放中间
    return res

# ========= 后序：左 右 根 → 入栈 【根, 右, 左】 =========
def postorder_iter_universal(root):
    res, stack = [], [root]
    while stack:
        cur = stack.pop()
        if cur is None: continue
        if isinstance(cur, int): res.append(cur)
        else:
            stack.extend([cur.val, cur.right, cur.left])  # ⚠️ val放最底下最后出=最后加=后序
    return res
```

#### 3. 层序遍历 BFS（⭐⭐⭐⭐⭐ 最常考）
```python
from collections import deque
def level_order(root):
    if not root: return []
    res, q = [], deque([root])
    while q:
        level_size = len(q)  # ⭐⭐⭐这行是层序灵魂！当前层大小定了之后这一层for循环固定拿level_size个
        level = []
        for _ in range(level_size):
            node = q.popleft()
            level.append(node.val)
            if node.left : q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
```

> 🔴 结论统一背：
> - 中序遍历 = BST升序序列（⭐必考性质：BST验证/第K小/恢复BST全靠这个）
> - 前序 + 中序 = 唯一确定重建二叉树；后序+中序也可以；前序+后序不行可能多种树

```python
from typing import List

def backtrack(选择列表, 起始位置):
```

### Q19. BST验证 / 插入 / 删除 / 第K小（⭐⭐⭐⭐⭐）

**【标准答案】**

BST性质：**中序遍历严格升序**；对任意节点：`left所有 < node.val < right所有`（必须满足所有子孙不是仅孩子）。

```python
class TreeNode:
    def __init__(self, x, l=None, r=None): self.val, self.left, self.right = x, l, r

# ============== ① 验证BST（Leet 98） ==============
# ❌ 常见错：只判 node.left.val<node.val && node.right.val>node.val
#    反例 5(4, 6(3,7))：右子树的3 < 根5，错判成合法
# ✅ 正解：每个节点带合法范围 (low, high)，递归缩范围
def is_valid_bst(root, low=float('-inf'), high=float('inf')):
    if not root: return True
    if not (low < root.val < high): return False
    # 左孩子所有 < root.val → 上限=root.val；右孩子所有 > root.val → 下限=root.val
    return is_valid_bst(root.left, low, root.val) and is_valid_bst(root.right, root.val, high)

# ============== ② 第K小元素（Leet 230，字节高频） ==============
# 解法1 中序迭代第K个退出 O(H+k) 最好
def kth_smallest(root, k):
    stack = []
    while stack or root:
        while root:
            stack.append(root); root = root.left
        root = stack.pop(); k -= 1
        if k == 0: return root.val
        root = root.right

# ============== ③ 插入节点（Leet 701） 找到空叶子插进去就行 ==============
def insert_into_bst(root, val):
    if not root: return TreeNode(val)
    if   val < root.val: root.left  = insert_into_bst(root.left, val)
    else               : root.right = insert_into_bst(root.right, val)
    return root

# ============== ④ ⚠️ 删除节点（Leet 450 最难 三种情况） ==============
def delete_node(root, key):
    if not root: return None
    if key < root.val:
        root.left = delete_node(root.left, key); return root
    if key > root.val:
        root.right = delete_node(root.right, key); return root
    # --- 找到了 要删除root！分三种情况 ---
    if not root.left : return root.right   # Case 1：只有右/无孩 直接返回右孩子接父
    if not root.right: return root.left    # Case 2：只有左 直接返回左孩子接父
    # Case 3：双子都有 → 找右子树最左的后继节点（比root大的最小那个）当新值 → 递归删后继
    succ = root.right
    while succ.left: succ = succ.left      # 找到后继
    root.val = succ.val                    # 值替换过来
    root.right = delete_node(root.right, succ.val)  # 删原来的后继
    return root
```

### Q20. 最近公共祖先 LCA（⭐⭐⭐⭐⭐ 100%常考）

**【标准答案】**

```python
class TreeNode:
    def __init__(self, x, l=None, r=None): self.val, self.left, self.right = x, l, r

# ============== BST的LCA（Leet 235 简单，利用大小左右分） ==============
def lca_bst(root, p, q):
    while True:
        if root.val > p.val and root.val > q.val: root = root.left   # 都在左
        elif root.val < p.val and root.val < q.val: root = root.right  # 都在右
        else: return root  # 一左一右 or 其中一个就是当前 → 找到了！

# ============== ⭐普通二叉树LCA（Leet 236 重点考递归后序） ==============
def lowest_common_ancestor(root, p, q):
    # base case：空返回空；当前是p/q之一返回当前（包含自己情况不用再找）
    if not root or root == p or root == q: return root
    left  = lowest_common_ancestor(root.left,  p, q)
    right = lowest_common_ancestor(root.right, p, q)
    # 四种情况合并：
    if not left : return right   # 左空 → 都在右，返回右找到的那个
    if not right: return left    # 右空 → 都在左，返回左找到的那个
    return root                  # 左右都非空 → p q 一左一右 → 当前就是LCA祖先
```

### Q21. 二叉树最大路径和（⭐⭐⭐⭐⭐ 字节必考题）

**【标准答案】**

> 🔥 坑点（必须讲清）：递归**返回值** 和 递归**里算全局答案** 完全是两个东西！
> - 返回值 = 当前节点作为**端点**的「单边路径最大和」→ 向上层父节点延伸用，只能选左或右一条腿走，不能分叉
> - 全局答案 = 当前节点作为**最高点**的「过根路径」→ 左子树腿 + 根值 + 右子树腿（分叉，相当于两条腿都走过根节点）

```python
class TreeNode:
    def __init__(self, x, l=None, r=None): self.val, self.left, self.right = x, l, r

class Solution:
    def max_path_sum(self, root):
        self.ans = float('-inf')  # 全局答案存成员变量 或传列表[0] mutable
        self._dfs(root)
        return self.ans

    def _dfs(self, node):
        if not node: return 0
        # ⭐ 左右子的单边最大和；负数贡献直接不要→取0（相当于不带上这棵子）
        L = max(self._dfs(node.left),  0)
        R = max(self._dfs(node.right), 0)
        # 1) 更新全局答案：过当前节点做顶点 = 根 + 左最大腿 + 右最大腿
        self.ans = max(self.ans, node.val + L + R)
        # 2) 返回给父节点的是"单边最大值"（只能选L或R中较大一条腿+自己）
        return node.val + max(L, R)

# ====== 测试：[-10,9,20,null,null,15,7] ======
# 最大路径是 15→20→7 和=42
t = TreeNode(-10, TreeNode(9), TreeNode(20, TreeNode(15), TreeNode(7)))
print(Solution().max_path_sum(t))  # 42
```

### Q22. 前缀Trie字典树 + 搜索II（通配符'.'匹配）（⭐⭐⭐⭐）

**【标准答案】**

```python
class TrieNode:
    def __init__(self):
        self.children = {}      # 字母 → TrieNode；26字母可用[None]*26更快
        self.is_end = False     # ✅ 关键标记：该节点是某个单词结尾（中间节点也要True）

class Trie:
    def __init__(self): self.root = TrieNode()

    # ---------- 插入单词 O(L) ----------
    def insert(self, word):
        p = self.root
        for ch in word:
            if ch not in p.children: p.children[ch] = TrieNode()
            p = p.children[ch]
        p.is_end = True

    # ---------- 精确匹配 O(L) ----------
    def search(self, word):
        p = self.root
        for ch in word:
            if ch not in p.children: return False
            p = p.children[ch]
        return p.is_end

    # ---------- 前缀匹配 O(L) ----------
    def starts_with(self, prefix):
        p = self.root
        for ch in prefix:
            if ch not in p.children: return False
            p = p.children[ch]
        return True

# ============= 进阶：Word Dictionary 添加单词+搜索带'.'通配符 Leet 211 =============
class WordDictionary:
    def __init__(self): self.root = TrieNode()
    def add_word(self, word):  # 和insert完全一样
        p = self.root
        for ch in word:
            if ch not in p.children: p.children[ch] = TrieNode()
            p = p.children[ch]
        p.is_end = True

    def search(self, word):
        # 遇到'.'要DFS遍历当前节点所有孩子！
        def dfs(node, i):
            if i == len(word): return node.is_end
            ch = word[i]
            if ch != '.':
                return ch in node.children and dfs(node.children[ch], i+1)
            else:  # 点 = 任何一个孩子能走通就行
                return any(dfs(child, i+1) for child in node.children.values())
        return dfs(self.root, 0)
```

### Q23. 二叉树序列化反序列化（⭐⭐⭐⭐⭐）

**【标准答案】**

> 思路：**前序遍历 + None用'#'标记** 能唯一重建。层序BFS也可以。
```python
class TreeNode:
    def __init__(self, x, l=None, r=None): self.val, self.left, self.right = x, l, r

class Codec:
    # ---------- 序列化：前序 空节点# 逗号分隔 O(n) ----------
    def serialize(self, root):
        res = []
        def dfs(n):
            if not n: res.append('#'); return
            res.append(str(n.val))
            dfs(n.left); dfs(n.right)
        dfs(root)

    def deserialize(self, data):

            v = next(arr)

            root = TreeNode(int(v))
            root.left  = dfs()
            root.right = dfs()
            return root
        return dfs()
```

### Q24. 回溯四题型：组合/排列/子集/分割 + 去重剪枝（⭐⭐⭐⭐⭐）

**【标准答案】**

> 代码参考Q18模板，这里总结差异 + 最常见的去重剪枝：

```python
# ========= 例：组合总和II Leet 40 数组中有重复数 每个数只能用一次 组合不重复 =========
from typing import List
class Solution40:
    def combination_sum2(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()  # 🔴 去重前提：排序让重复数挨在一起
        res, path, n = [], [], len(candidates)
        used = [False] * n

        def backtrack(start, remain):
            if remain == 0:
                res.append(path.copy()); return
            for i in range(start, n):
                if candidates[i] > remain: break  # 剪枝1：当前数就超过剩余，后面更大直接break
                # 剪枝2：去重同层重复！i>start(不是第一个) + 和前一个相同 + 前一个没用过(说明在同层)才剪
                if i > start and candidates[i] == candidates[i-1] and not used[i-1]: continue
                used[i] = True; path.append(candidates[i])
                backtrack(i + 1, remain - candidates[i])  # 每个数只能用一次 → i+1
                used[i] = False; path.pop()
        backtrack(0, target)
        return res
```

#### 🔥 去重剪枝三原则（背死）
1. **先排序**：相同元素挨在一起
2. **剪同一层重复**（横向）：`if i > start && a[i]==a[i-1] && !used[i-1]` → 这层前面兄弟节点已经走过相同值，再走必重复
3. **剪超过目标的提前break**（有序数组前提）

### Q25. 岛屿系列：数量/周长/最大面积/沉没中围（⭐⭐⭐⭐⭐ 高频题族）

**【标准答案】**

> 万能解法 = DFS + 4方向扩散 + 原地标记visited(直接把2改成0，省extra S)

```python
# ========== ① 岛屿数量 Leet 200 ==========
class Solution200:
    def num_islands(self, grid):
        n, m, cnt = len(grid), len(grid[0]), 0
        def dfs(i, j):
            if not (0 <= i < n and 0 <= j < m) or grid[i][j] != '1': return
            grid[i][j] = '0'  # 标记visited，省掉额外visited矩阵！
            for di, dj in ((1,0), (-1,0), (0,1), (0,-1)):
                dfs(i+di, j+dj)
        for i in range(n):
            for j in range(m):
                if grid[i][j] == '1':
                    dfs(i, j); cnt += 1  # 每发现一次连通块 +1
        return cnt

# ========== ② 岛屿最大面积 Leet 695 ==========
class Solution695:
    def max_area_of_island(self, grid):
        n, m, ans = len(grid), len(grid[0]), 0
        def dfs(i, j):
            if not (0 <= i < n and 0 <= j < m) or grid[i][j] != 1: return 0
            grid[i][j] = 0
            return 1 + sum(dfs(i+di, j+dj) for di, dj in ((1,0),(-1,0),(0,1),(0,-1)))
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 1: ans = max(ans, dfs(i, j))
        return ans

# ========== ③ 岛屿周长 Leet 463 (只有一个岛 没湖) ==========
# 周长 = 每个1贡献4条边 - 每相邻1对多算2条
class Solution463:
    def island_perimeter(self, grid):
        n, m = len(grid), len(grid[0])
        cnt1 = adjacent = 0
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 1:
                    cnt1 += 1
                    if i+1 < n and grid[i+1][j] == 1: adjacent += 1  # 下邻居
                    if j+1 < m and grid[i][j+1] == 1: adjacent += 1  # 右邻居
        return cnt1 * 4 - adjacent * 2
```

### Q26. 拓扑排序 BFS Kahn入度表 vs DFS三色标记（⭐⭐⭐⭐⭐）

**【标准答案】**

> 拓扑排序 = 把DAG有向无环图排成一条线性序列，所有依赖关系在前面。有环就排不出来，返回空。
> 应用：课程表(先修课后修课) / 编译依赖 / 任务调度 / "终在安全状态"

```python
from collections import deque

# ========== 方案A：⭐Kahn BFS入度表 O(V+E) 99%写这个好记 ==========
def topo_sort_kahn(n, edges):
    indeg = [0] * n               # 每个点的入度
    g = [[] for _ in range(n)]    # 邻接表
    for u, v in edges:            # u → v：先上u课，才能上v课
        g[u].append(v); indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)  # 所有入度=0的起点入队
    res = []
    while q:
        u = q.popleft(); res.append(u)
        for v in g[u]:
            indeg[v] -= 1         # 邻居入度都少1
            if indeg[v] == 0: q.append(v)
    return res if len(res) == n else []  # 排不完=有环！返回空

# 例：Leet 207 课程表能否上完？  return 有环吗？ 不空就True
def can_finish_courses(n, prerequisites):
    # prerequisites = [[要上a,必先上b]] = b→a
    return len(topo_sort_kahn(n, [(b, a) for a, b in prerequisites])) == n

# ========== 方案B：DFS三色标记 判环 （面试加分答） ==========
def topo_sort_dfs(n, edges):
    W, G, B = 0, 1, 2  # 白=没访问过 灰=递归中 黑=全子孙访问完
    color, res = [W]*n, []
    g = [[] for _ in range(n)]
    for u,v in edges: g[u].append(v)
    def dfs(u):
        color[u] = G
        for v in g[u]:
            if color[v] == G: return False  # 子是灰色=访问到正在递归中的祖先=有环！
            if color[v] == W and not dfs(v): return False
        color[u] = B
        res.append(u)
        return True
    for u in range(n):
        if color[u] == W and not dfs(u): return []
    return res[::-1]  # 后序的逆序 = 拓扑序
```

```python
# Leet 127 单词接龙：beginWord → endWord 每步变一个字母；返回最少步数 变不过去0
def ladder_length(begin_word, end_word, word_list):
    word_set = set(word_list)
    if end_word not in word_set: return 0
    q, steps = deque([(begin_word, 1)]), {begin_word}
    while q:
        w, step = q.popleft()
        if w == end_word: return step
        for i in range(len(w)):  # 26字母替换每一位找邻居
            for c in 'abcdefghijklmnopqrstuvwxyz':
                nw = w[:i] + c + w[i+1:]
                if nw in word_set and nw not in steps:
                    steps.add(nw); q.append((nw, step + 1))
    return 0
```

### Q28. 0-1矩阵多源BFS（⭐⭐⭐⭐）

**【标准答案】**

> Leet 542 给定01矩阵，返回每个格子到**最近0**的距离
> 🔥 超级源点：所有0一次性提前入队，一起扩散！每个格子第一次被访问时 = 最近的距离。

```python
from collections import deque
def update_matrix(mat):
    n, m = len(mat), len(mat[0])
    dist = [[-1]*m for _ in range(n)]
    q = deque()
    # ⭐⭐⭐ 多源：所有0同时当起点，直接入队 dist=0
    for i in range(n):
        for j in range(m):
            if mat[i][j] == 0:
                dist[i][j] = 0; q.append((i, j))
    while q:
        i, j = q.popleft()
        for di, dj in ((1,0),(-1,0),(0,1),(0,-1)):
            ni, nj = i+di, j+dj
            if 0 <= ni < n and 0 <= nj < m and dist[ni][nj] == -1:
                dist[ni][nj] = dist[i][j] + 1
                q.append((ni, nj))
    return dist
```

> 面试追问：为什么不对每个1单独BFS？A：那样T=O(n²m²)超时。多源一次全入队 = O(nm)完美秒杀。

### Q30. 背包6模型 + 01/完全容量遍历顺序（⭐⭐⭐⭐⭐ 字节美团高频）

**【标准答案】**

#### 总纲：动规 + 3维组合(3问 × 2遍历序 × 2初始化) = 所有背包题秒杀

| 模型名 | 每种物品可用次数 | 容量遍历顺序（最关键！） | 代表性题 |
|-------|---------------|--------------------|-------|
| ✅ 0-1 背包 | 1次 | **倒序 i 从C→wt**（防重复选同一物品） | 分割等和子集、最后一块石头重量II、目标和 |
| ✅ 完全背包 | 无限次 | **正序 i 从wt→C** | 零钱兑换、硬币组合、爬楼梯、完全平方数 |
| 多重背包 | cᵢ 次 | 二进制拆分 or 单调队列优化后等同01 | 少见 |
| 分组背包 | 每组最多选1个 | 组外倒序容量，组内for物品 | Leet2218 从栈中取出K个硬币最大和 |
| 二维费用背包 | 两个容量(重+体) | 两层容量都倒序 | 一和零 Leet474 |
| 混合背包 | 1次/无限/c次混 | 判断每个物品是01/完全 对应序 | 少见 |

```python
# ========== 黄金 0-1 背包模板：wt重量 val价值 C容量 → 最大价值 ==========
def knapsack_01(wt, val, C):
    n, dp = len(wt), [0] * (C + 1)
    for i in range(n):                 # 外层：物品
        for j in range(C, wt[i] - 1, -1):  # ⭐⭐⭐内层：容量 倒序！（01专属）
            dp[j] = max(dp[j], dp[j - wt[i]] + val[i])
    return dp[C]

# ========== 完全背包 = 零钱兑换II Leet 518：多少种组合凑成amount？ ==========
# 求组合数（顺序不同算同一种：1+2和2+1算一种 硬币不分先后） → 外层物品 内层容量正序
def coin_change_2_combinations(amount, coins):
    dp = [0] * (amount + 1); dp[0] = 1  # ⭐ 组合数初始化：0元=1种空方案（非常重要）
    for c in coins:                         # 外层：硬币
        for i in range(c, amount + 1):      # ⭐内层：容量正序（完全背包）
            dp[i] += dp[i - c]
    return dp[amount]

# ========== 爬楼梯进阶 / 排列数 = 求顺序不同算不同 ==========
# 步长coins=[1,2,3] 上amount台阶多少种走法？1+2 vs 2+1算两种
def climb_stairs_permutations(amount, coins):
    dp = [0] * (amount + 1); dp[0] = 1
    for i in range(1, amount + 1):          # ⭐⭐⭐ 外层：背包总目标正序
        for c in coins:                     # ⭐⭐⭐ 内层：放物品
            if i >= c: dp[i] += dp[i - c]
    return dp[amount]
```

> 🔴 组合 vs 排列 终极秒杀：**外物品 = 组合；外背包 = 排列**

### Q31. 子序列DP：LCS最长公共 / LIS最长递增 O(n²)/贪心+二分O(nlogn)（⭐⭐⭐⭐⭐）

**【标准答案】**

```python
# ========= ① 最长公共子序列 LCS Leet 1143 O(nm) =========
def longest_common_subsequence(text1, text2):
    n, m = len(text1), len(text2)
    dp = [[0]*(m+1) for _ in range(n+1)]  # dp[i][j] = t1前i,t2前j 的LCS长度
    for i in range(1, n+1):
        for j in range(1, m+1):
            if text1[i-1] == text2[j-1]: dp[i][j] = dp[i-1][j-1] + 1
            else:                        dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[n][m]

# ========= ② ⭐ 最长递增子序列 LIS / 俄罗斯套娃信封 O(n²) =========
def length_of_lis_o_n2(nums):
    n = len(nums)
    dp = [1] * n  # dp[i]=以i结尾的LIS长度 最小是自己1
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:  # 前面的能接在j后面
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

# ========= ②+ ⭐🔥 贪心+二分 LIS O(n log n) 生产大数据必须 =========
# 牌堆顶牌堆法：新牌>当前所有堆顶→新开堆；否则放第一个比它大的堆顶上覆盖
# 堆的数量 == LIS长度！（LIS不要求连续）
import bisect
def length_of_lis_optimal(nums):
    tails = []  # tails[i]=长度为i+1的LIS的最小可能末尾值
    for x in nums:
        idx = bisect.bisect_left(tails, x)  # 第一个>=x的堆
        if idx == len(tails): tails.append(x)
        else                : tails[idx] = x  # 覆盖 让它更小更易加新
    return len(tails)
```

> 面试追问：最长公共子串（连续）和子序列区别？A：公共子串要求连续，转移方程`相等=dp[i-1][j-1]+1 不等=0`，答案是max(dp)。

```python
# Leet 72：word1 → word2 最少操作（插入/删除/替换 算1步）
def min_distance(w1, w2):
    n, m = len(w1), len(w2)
    # dp[i][j] = w1前i个字符 → w2前j个字符 的最少操作
    dp = [[0]*(m+1) for _ in range(n+1)]
    for i in range(n+1): dp[i][0] = i  # 初始化：删i次
    for j in range(m+1): dp[0][j] = j  # 初始化：插j次
    for i in range(1, n+1):
        for j in range(1, m+1):
            if w1[i-1] == w2[j-1]:
                dp[i][j] = dp[i-1][j-1]  # 字符相等直接继承 不用操作
            else:
                # 三操作取最小 + 1步：删(w1减1) / 插(w2减1等价w1加) / 替换两个都减1
                dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
    return dp[n][m]
```

### Q33. 股票6道题 dp[i][k][0/1]状态机（⭐⭐⭐⭐⭐）

**【标准答案】**

> 通用状态机：`dp[i][k][0/1]` = 第i天、已做k次交易、0=不持有 / 1=持有 的最大利润
> 转移：`0不持有 = max(昨天就不持有，昨天持有今天卖掉)`；`1持有 = max(昨天就持有，昨天不持有今天买)`
> 冷冻期k-1延迟、手续费卖时扣、k=∞无限交易 k都相同可以省掉

```python
# ======== ① 冷冻期1天 Leet 309：卖完后第二天不能买 ========
def max_profit_cool(prices):
    if not prices: return 0
    n = len(prices)
    hold, sold, rest = float('-inf'), float('-inf'), 0
    # hold=持有; sold=刚卖(今天结束后不持有且是卖的); rest=不持有且不是刚卖的(可以买)
    for p in prices:
        pre_hold, pre_sold, pre_rest = hold, sold, rest
        hold = max(pre_hold, pre_rest - p)   # 持有：之前就持有 / 之前cool完今天买
        sold = pre_hold + p                  # 卖了：之前持有今天卖
        rest = max(pre_rest, pre_sold)       # 休息：之前就休息 / 昨天卖今天休息
    return max(sold, rest)

# ======== ② k笔交易最多 Leet 188：通用k次版 ========
def max_profit_k_transactions(k, prices):
    n = len(prices)
    if k >= n // 2:  # k特别大=等同无限次 用II简单版
        return sum(max(0, prices[i]-prices[i-1]) for i in range(1, n))
    dp = [[[0]*2 for _ in range(k+2)] for _ in range(n+1)]
    for i in range(n+1):
        for kk in range(k+2):
            dp[i][kk][1] = float('-inf')
    for i in range(1, n+1):
        for kk in range(1, k+1):
            dp[i][kk][0] = max(dp[i-1][kk][0], dp[i-1][kk][1]   + prices[i-1])  # 卖 不变k
            dp[i][kk][1] = max(dp[i-1][kk][1], dp[i-1][kk-1][0] - prices[i-1])  # 买 k+1
    return dp[n][k][0]
```

```python
# ===== ① 一排房子 I =====
def rob_1(nums):
    dp0, dp1 = 0, 0  # dp0=前i个最后一个不偷的最大  dp1=偷的最大
    for n in nums:
        dp0, dp1 = max(dp0, dp1), dp0 + n
    return max(dp0, dp1)

# ===== ② ⭐环形 II 首尾相连 首和尾不能同时偷 =====
# 技巧：拆成两个直线版 max([0..n-2不偷最后], [1..n-1不偷最前])
def rob_2(nums):
    if len(nums) == 1: return nums[0]
    def rob1(arr):
        dp0 = dp1 = 0
        for n in arr: dp0, dp1 = max(dp0, dp1), dp0 + n
        return max(dp0, dp1)
    return max(rob1(nums[:-1]), rob1(nums[1:]))

# ===== ③ 二叉树版 III 后序遍历返回两个状态 =====
class TreeNode:
    def __init__(self, x, l=None, r=None): self.val, self.left, self.right = x, l, r
class Solution337:
    def rob_3(self, root):
        def dfs(node):  # return [不偷当前最大, 偷当前最大]
            if not node: return [0, 0]
            L = dfs(node.left); R = dfs(node.right)
            no_rob = max(L) + max(R)                              # 不偷：孩子随便选最大
            do_rob = node.val + L[0] + R[0]                      # 偷：孩子都不能偷
            return [no_rob, do_rob]
        return max(dfs(root))
```

### Q35. 最短路径四算法对比（⭐⭐⭐⭐ 图论第一问）

**【标准答案】**

| 算法 | 边权要求 | 求的是 | 时间复杂度 | 典型场景 | 一句话怎么实现 |
|-----|---------|-------|-----------|---------|-------------|
| 🟩 BFS（无权） | **权重都=1** | 单源最短 | O(V+E) | 走迷宫步数、word ladder | 队列，首次访问即最短 |
| 🟥 ⭐ Dijkstra迪杰斯特拉 | **非负权 ≥0** | 单源最短 | 堆优化**O(E log V)** | 地图导航、最常见 | 小顶堆pop最小距离点 + 松弛邻居；贪心思想 |
| 🟦 Bellman-Ford SPFA优化 | **可以有负权 能判负环** | 单源最短 / 判负环 | BF=O(VE) / SPFA平均O(E) | 有负边的图、差分约束 | 对每条边松弛V-1次；第V次还能松弛就有负环 |
| 🟨 Floyd-Warshall弗洛伊德 | 无负环即可 | **多源任意两点** 最短 | **O(V³)** | 图很小V≤500、想一次算出所有点对 | 三重for k中介点→i→j: `dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])` |

```python
# ========= 最常用：Dijkstra 堆优化模板 =========
import heapq
def dijkstra(n, edges, start):
    g = [[] for _ in range(n)]
    for u, v, w in edges: g[u].append((v, w))
    INF = float('inf')
    dist = [INF] * n; dist[start] = 0
    heap = [(0, start)]  # (当前最短距离, 点) 小顶堆
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]: continue  # 旧数据跳过（lazy删除）
        for v, w in g[u]:
            if dist[v] > d + w:
                dist[v] = d + w
                heapq.heappush(heap, (dist[v], v))
    return dist

# ========= Floyd 多源最短 =========
def floyd(n, edges):
    INF = float('inf')
    dp = [[INF]*n for _ in range(n)]
    for i in range(n): dp[i][i] = 0
    for u, v, w in edges: dp[u][v] = w
    for k in range(n):           # 第一层：中介点k
        for i in range(n):
            for j in range(n):
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k][j])
    return dp
```

> 面试追问：Dijkstra为什么有负边就错？A：贪心选最小距离点以后认为不可能再短；有负边后面来个-10000可能让它变得更短，贪心就错了。
