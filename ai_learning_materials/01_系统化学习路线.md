# 01 - AI转型系统化学习路线

> 适用人群: 2-3年 Java/Android/Vue开发经验, 希望转型AI相关岗位
> 核心理念: 不是从零开始, 而是将现有工程能力与AI知识做乘法叠加

---

## 第一部分: 基础知识 (入门阶段, 1-2个月)

### 1.1 数学基础 (仅核心概念, 不做深入推导)

| 知识点 | 核心内容 | 与现有技术结合 |
|--------|---------|-----------------|
| 矩阵运算 | 矩阵乘法、转置、逆矩阵 | 特征数据处理、模型参数 |
| 向量空间 | 向量、向量范数、距离度量 | 向量检索、相似度计算 |
| 概率分布 | 高斯分布、条件概率、贝叶斯定理 | 模型输出解释、朴素贝叶斯 |
| 微积分概念 | 梯度、偏导数、链式法则 | 梯度下降、反向传播理解 |

### 1.2 Python工具链 (快速上手)

| 工具 | 用途 | 学习目标 |
|------|-----|---------|
| NumPy | 数值计算基础 | 能做数组运算、矩阵操作 |
| Pandas | 数据处理与分析 | 能读取CSV、数据清洗 |
| Matplotlib | 数据可视化 | 能画训练曲线、分布图 |
| scikit-learn | 传统ML | 能做分类/回归/聚类 |
| Jupyter | 交互式开发 | 能写分析笔记、实验报告 |

### 1.3 机器学习基础 (理解核心思想)

1. 监督学习:
   - 线性回归/逻辑回归 (理解线性模型)
   - 决策树/随机森林 (理解集成学习)
   - 支持向量机 (理解核方法思想)
   - 模型评估: 准确率/精确率/召回率/F1/混淆矩阵

2. 无监督学习:
   - K-Means聚类
   - PCA降维

3. 核心概念:
   - 训练集/验证集/测试集
   - 过拟合与欠拟合
   - 偏差-方差权衡

### 1.4 深度学习基础 (神经网络入门)

| 概念 | 通俗解释 | 代码实践 |
|------|---------|---------|
| 神经网络 | 多层感知机: 输入->隐藏层->输出 | PyTorch实现MNIST |
| 激活函数 | ReLU/Sigmoid/Tanh | 在模型中选择使用 |
| 损失函数 | MSE/CrossEntropy | 分类用CrossEntropy, 回归用MSE |
| 梯度下降 | 沿梯度方向更新参数 | SGD/Adam优化器 |
| 反向传播 | 链式法则求梯度 | PyTorch自动微分 |
| CNN | 卷积: 提取局部特征 | CIFAR-10图像分类 |
| Transformer | 自注意力: 捕捉序列关系 | 理解BERT/GPT的区别 |

### 1.5 第一阶段项目实践

项目1: 用scikit-learn做房价预测 (sklearn入门)
- 数据: Kaggle House Prices 或 简化数据集
- 目标: 理解特征工程、模型选择、结果分析
- 产出: 一个完整的Jupyter notebook

项目2: 用PyTorch做手写数字识别 (深度学习入门)
- 数据: MNIST数据集
- 目标: 理解训练循环、损失曲线、准确率
- 产出: 可训练模型 + 训练日志

## 第二部分: 进阶知识 (中级阶段, 2-3个月)

### 2.1 深度学习进阶 (核心模型架构)

1. CNN进阶:
   - ResNet/DenseNet/EfficientNet (现代图像模型)
   - 目标检测: YOLO系列 (一阶段检测)
   - 图像分割: U-Net架构 (医疗/自动驾驶场景)

2. RNN/LSTM/GRU (序列建模)

3. Transformer深入:
   - 自注意力机制详解
   - BERT (双向编码, 用于理解)
   - GPT (自回归解码, 用于生成)
   - 位置编码/多头注意力/残差连接

### 2.2 AI工程化实践 (从模型到产品)

| 环节 | 传统工程知识迁移 | 新知识学习 |
|------|-------------|---------|
| 模型训练 | 类似持续集成 | 超参数调优/早停/学习率调度 |
| 模型保存 | 类似发布版本 | ModelCheckpoint/模型格式选择 |
| 模型转换 | 类似编译打包 | ONNX格式转换/量化 |
| 模型部署 | 类似服务部署 | TensorFlow Serving/ONNX Runtime |
| 性能监控 | 类似APM | 推理延迟/吞吐量/准确率监控 |

### 2.3 AI与Java后端结合 (你的主战场1: AI推理服务)

技术栈:
- Spring Boot 3 (你已掌握
- ONNX Runtime Java (新知识)
- Deep Java Library (DJL, 亚马逊开源)
- 向量数据库 (Qdrant/Milvus/pgvector)

关键能力:
1. 将PyTorch/TensorFlow训练的模型 -> ONNX格式
2. 在Java后端加载模型 -> 推理预测
3. 将推理服务封装为REST API
4. 性能优化: 批处理/多线程/缓存策略
5. 监控推理性能和成本

典型应用:
- 智能推荐系统
- 内容安全审核
- 图像/文本分类服务
- 风险评估模型

### 2.4 AI与Android结合 (你的主战场2: 端侧AI)

技术栈:
- CameraX (你已掌握)
- TensorFlow Lite (推理引擎)
- NNAPI/NPU加速 (厂商SDK)
- 模型量化优化 (新知识)

关键能力:
1. 在Android设备上加载和运行模型
2. 实时处理相机帧 -> 预处理 -> 推理 -> 后处理
3. 模型文件大小/推理延迟/准确率的权衡
4. 端侧与云端AI的分工与协作

典型应用:
- 实时物体检测相机
- 离线OCR文字识别
- 语音助手端侧回复
- 本地推荐/行为识别

### 2.5 AI与Vue前端结合 (你的主战场3: AI交互体验)

技术栈:
- Vue 3 + TypeScript (你已掌握)
- TensorFlow.js (浏览器端推理)
- 流式API调用 (fetch/SSE)
- Markdown渲染/代码高亮

关键能力:
1. 在前端展示AI结果
2. 调用后端推理API
3. 实现流式文本渲染 (打字机效果)
4. 多模态输入 (文本+图像+语音)

典型应用:
- AI聊天机器人界面
- 智能写作助手
- 图像生成前端
- 代码辅助工具

### 2.6 LLM应用开发 (RAG/Agent)

1. RAG (检索增强生成):
   - 文档解析(PDF/Word/Markdown/HTML)
   - 文本切分 (Chunking策略)
   - 向量生成 (Embedding模型)
   - 向量检索 (ANN索引)
   - 重排序 (Rerank)
   - LLM生成 (最终答案)

2. Agent (智能体):
   - LLM + 工具调用 (Tool Calling)
   - 规划 (Planning)
   - 记忆 (Memory)
   - 多步推理能力

3. Prompt工程:
   - 角色定义/上下文注入/少样本学习/思维链提示

## 第三部分: 高级知识与专项深入 (高级阶段, 持续成长)

### 3.1 模型部署与优化

| 技术 | 解决的问题 | 与你的应用场景 |
|------|-----------|--------------|
| 模型量化 | 减少模型大小, 加速推理 | 端侧AI部署/高并发推理 |
| 知识蒸馏 | 小模型学习大模型 | 用大模型教小模型 |
| 剪枝 | 移除不重要的权重 | 模型压缩/加速推理 |
| 模型并行 | 大模型切分到多设备 | 超大模型推理 |
| vLLM/Text Generation Inference | LLM高吞吐推理 | 高并发LLM服务 |

### 3.2 MLOps (AI工程化体系)

概念: 将DevOps思想应用到AI/ML领域

核心环节:
- 数据版本管理 (DVC)
- 模型注册中心 (MLflow)
- 训练流水线 (自动化训练)
- 模型服务化 (标准化部署)
- 线上监控 (性能+质量)
- A/B测试 (新旧模型对比)

### 3.3 行业应用与深入方向选择

方向A: LLM应用开发 (需求最大, 入门门槛适中)
核心技能:
- RAG系统设计与优化
- Agent框架与工具调用
- 提示词工程与评估
- 多模态应用

方向B: 端侧AI工程 (结合你Android经验优势)
核心技能:
- TFLite/ONNX Runtime端侧部署
- NPU/GPU加速与算子优化
- 模型量化与压缩技术
- 端云协同系统设计

方向C: AI平台工程 (结合Java后端优势)
核心技能:
- 模型服务化架构
- 推理性能优化
- 监控与告警体系
- 多租户与成本优化

方向D: 搜索/推荐/广告工程 (传统数据驱动+AI升级)
核心技能:
- 召回/粗排/精排架构
- 用户画像与特征工程
- 实时特征与离线特征
- 实验平台与A/B测试

## 学习路线阶段总结

```
  第1-2月: 基础打牢
  Python + 机器学习 + 深度学习基础 + 第一个AI项目

  第3-4月: 与现有技能融合
  Java后端推理 + Android端侧AI + Vue前端AI交互

  第5-6月: LLM应用与工程化
  RAG + Agent + 向量数据库 + 完整项目

  第7-12月: 专项深入与成长
  选定1-2个方向深挖，持续深入，项目落地
```

> 关键成功的学习不是一蹴而就的, 需要在做中学, 用项目驱动学习
> 每学一个知识点，都要做一个小项目来验证和巩固
> 持续学习 + 持续实践 + 持续输出
