## 3.2 传统项目的AI赋能改写方法

### 改写公式：传统功能 + AI能力 = 新简历亮点

**示例1：电商App → AI赋能电商App**
- 原版：实现商品列表、购物车、订单管理
- AI赋能版：
  - 集成TFLite实现**拍照识商品**功能（端侧图像分类）
  - 用ML Kit实现**条形码扫描**自动添加商品
  - 用LLM API实现**智能客服**（流式输出 + 多轮对话）
  - **技术栈**：Android + TFLite + ML Kit + OkHttp SSE

**示例2：后台管理系统 → AI赋能管理平台**
- 原版：用户管理、权限控制、数据报表
- AI赋能版：
  - 集成DJL实现**异常行为检测**（ONNX模型推理）
  - 用LangChain4j实现**智能数据分析助手**（RAG + 数据库查询）
  - 用MLflow实现**模型版本管理**（Staging/Production切换）
  - **技术栈**：Spring Boot + DJL + LangChain4j + MLflow

**示例3：前端展示页面 → AI赋能交互界面**
- 原版：数据可视化、表单提交、列表展示
- AI赋能版：
  - 用TF.js实现**浏览器端图像分类**（零服务器推理成本）
  - 用SSE实现**流式AI对话界面**（打字机效果 + Markdown渲染）
  - 用ECharts实现**Embedding向量3D可视化**
  - **技术栈**：Vue 3 + TF.js + Fetch ReadableStream + ECharts

## 3.4 简历项目描述模板

### 项目1：端侧AI图像分类App（Android）

```
【项目名称】端侧AI实时图像分类App
【技术栈】Kotlin + CameraX + TensorFlow Lite + MPAndroidChart
【项目描述】
- 基于MobileNetV2实现端侧图像分类，支持1000类ImageNet识别
- 使用CameraX实现实时摄像头预览，每帧推理耗时<50ms
- 实现INT8模型量化，模型大小从14MB降至3.5MB，推理速度提升2x
- 使用GPU Delegate加速，推理耗时从35ms降至5ms（Pixel 7）
- 用MPAndroidChart可视化展示各类别置信度分布
【技术亮点】
- 掌握TFLite Interpreter完整流程：模型加载→ByteBuffer预处理→推理→后处理
- 理解模型量化（PTQ）原理及精度/大小权衡
- 熟悉CameraX ImageAnalysis回调中的YUV→RGB格式转换优化
```
