# 05 - 简历优化指南与项目包装策略

> 核心: 你不是转行, 而是升级 - 从传统工程师升级为 AI-enabled 工程师

---

## 5.1 简历结构与核心原则

推荐结构 (单页A4, 最多2页):

1. 基本信息 (姓名/电话/邮箱/GitHub/博客/所在地)
2. 个人简介/专业技能 (3-5句话, 突出差异化价值)
3. 工作经历 (倒序, 2-3家公司, 每家3-5个项目亮点)
4. AI相关项目 (选2-3个最能体现AI能力的项目详细描述)
5. 技术栈清单 (按熟练度排序, AI相关技能突出标注)
6. 教育背景 + 证书/课程 (可选, 有亮点才写)
7. 开源贡献/技术文章 (可选, 有质量才写)

核心原则:
- STAR原则: Situation -> Task -> Action -> Result, 每个项目亮点都用此结构
- 用数据说话: '提升了性能'不够, 要'P99延迟从800ms降低到250ms, 降低69%'
- 动词开头: 设计/实现/优化/重构/主导/负责/推进/解决
- 关键词优先: 看目标岗位JD, 将JD中的关键词自然融入你的简历
- 无废话: 每一句话都应该让面试官觉得'这个人值得约来聊聊', 否则删掉

- 实现多LLM供应商适配层, 可无代码切换OpenAI/Claude/国产模型

成果与数据:

## 5.6 常见简历问题与修复建议

问题1: 项目描述全是'参与了XX'/'协助了XX', 看不出个人贡献
修复: 用'我主导了XX'/'我设计了XX'/'我实现了XX', 明确你的责任范围

问题2: 描述太笼统, '做了后端开发'
修复: '用Spring Boot + MySQL重构了用户服务, 接口P99延迟从320ms降到80ms,
      并发支持从500QPS提升到3000QPS, 服务器成本降低40%'

问题3: AI相关内容太少, 不像AI岗位简历
修复:
- 在技术栈中单独列出AI技能
- 在项目描述中融入AI词汇 (模型/推理/Embedding/向量检索/RAG等)
- 即使没有生产环境AI项目, 也要写自学的AI项目 (GitHub链接)

问题4: 数据太少, 没有量化成果
修复: 每个项目亮点至少有一个数据:
- 性能类: 延迟/吞吐量/QPS/内存占用/包体积
- 业务类: 用户数/DAU/GMV/转化率/留存率/成本节省
- 质量类: 崩溃率/错误率/代码覆盖率/发布频率

问题5: 太长太啰嗦, 关键信息被淹没
修复: 控制在1-2页内, 每一页都要值得读, 用bullet point而非大段文字

## 5.7 投递策略

岗位类型优先级建议:

Tier 1 (最高优先级 - 你的差异化优势最大):
- AI应用工程师 / LLM应用工程师
- 端侧AI工程师 / 移动端AI工程师
- AI平台工程师 / AI基础设施工程师
- 智能搜索/推荐/广告工程师

Tier 2 (次高优先级 - 传统技能也很重要):
- 全栈工程师 (已有AI元素的公司/项目)
- Java后端工程师 (需要做AI服务化的团队)
- Android/iOS开发工程师 (AI/AR/VR方向)
- 数据工程师 / 数据平台工程师

Tier 3 (低优先级 - 竞争太激烈, 差异化不明显):
- 纯算法工程师 / 算法研究员 (需要论文和顶会背景)
- 纯机器学习工程师 (需要丰富建模经验)
- CV/NLP研究员 (需要专业方向深度积累)

投递策略:
- 精投而非海投: 每投递一家公司, 都针对其JD微调简历
- 优先投内推: 内推通过率比官网高3-10倍
- 投递时机: 金三银四/金九银十是旺季, 但AI岗位全年都有招聘
- 投递后1-2周无反馈: 可礼貌跟进一次, 但不要反复骚扰

## 5.8 面试准备清单

技术准备:
- Java基础: 集合源码/JVM/并发/异常处理 (面试必问)
- Android基础: 四大组件/消息机制/绘制流程/性能优化 (面Android必问)
- Vue/JS基础: 响应式原理/生命周期/虚拟DOM (面前端必问)
- 算法题: LeetCode Top 200, medium为主 (大厂必考, 小厂概率低)
- AI基础: 本资料04-A的内容, 能讲清核心概念
- 系统设计: 04-G的系统设计题, 能画出架构图并讲清楚
- 你的项目: 每一个项目都要能讲5分钟, 画出架构图, 解释你的设计决策

非技术准备:
- 自我介绍: 准备3个版本 (30秒/1分钟/3分钟)
- 项目故事: 每个项目准备3个版本 (一句话/1分钟/5分钟)
- 职业规划: 3年/5年规划, 为什么选这个方向, 为什么选这家公司
- 薪资预期: 了解市场行情, 准备一个合理的期望范围
- 反向提问: 准备3-5个问面试官的问题 (体现你的思考深度)

## 5.9 职业发展路径建议

短期(0-1年):
- 目标: 成功入职AI相关岗位, 完成技术转型
- 关键: 扎实的工程能力 + 入门级AI知识 + 1-2个像样的AI项目
- 预期: 对AI从陌生到熟悉, 能独立完成AI应用开发任务

中期(1-3年):
- 目标: 成为合格的AI应用/工程工程师, 在某一方向建立专业深度
- 方向选择建议:
  a. LLM应用层: RAG/Agent/工具链/评估体系 (需求最大, 入门门槛适中)
  b. 端侧AI: 移动/边缘设备上的模型部署与优化 (结合你Android经验优势)
  c. AI平台工程化: 模型服务化/MLOps/推理优化 (Java后端经验可复用)
  d. 搜索/推荐/广告: 传统数据驱动方向 + AI能力升级 (需求稳定)

长期(3-5年):
- 目标: 成为技术专家/技术负责人, 能独立设计和推进中型AI系统
- 关键: 技术深度 + 业务理解 + 项目管理能力 + 团队影响力
- 备选: 如果发现自己更适合做纯AI算法, 可以继续往算法方向深造
        如果发现自己更适合做产品/管理, 可以往技术管理方向转型
