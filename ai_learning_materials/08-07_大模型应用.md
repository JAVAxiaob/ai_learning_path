### RAG（检索增强生成）完整链路

```
索引阶段（离线）:
  文档文件 → DocumentLoader（PyPDF/Unstructured）
           → RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
           → Embeddings (如BGE/Sentence-BERT/OpenAI text-embedding-3)
           → VectorStore.add_documents() [Chroma / FAISS / Milvus]

检索阶段（在线）:
  用户Query → QueryTransform (改写/压缩/多查询生成)
           → VectorStore.similarity_search_with_score(query, k=5)
           → 重排序 (Cross-Encoder / BGE-reranker)
           → Prompt组装 (Context + 用户问题)
           → LLM.generate()
           → 流式输出 (Streaming)
           → 溯源引用 (citation/source)
```

**RAG关键参数**：
- chunk_size: 文档切分大小（500-2000 tokens），越小越精准但上下文碎片
- chunk_overlap: 切分重叠（50-100 tokens），避免上下文断裂
- top-k: 检索返回文档数（3-10），越多上下文越多但token成本高
- 重排序：Cross-Encoder对top-k重新打分，显著提升召回精度

### Agent核心机制：ReAct模式（思考-行动-观察循环）

```
用户问题: "帮我计算2024年北京7月的平均气温"
  ↓
LLM思考: "我需要先知道2024年7月北京的气温数据。
          应该使用天气查询工具获取历史数据，
          然后用计算器计算平均值。"
  ↓
LLM行动: tool=weather_api, params={"city":"Beijing","month":"2024-07"}
  ↓
工具执行 → 观察: 返回每天的气温数据 (31条记录)
  ↓
LLM思考: "已获取数据。现在需要提取所有气温并计算平均值。"
  ↓
LLM行动: tool=calculator, params={"expression":"(32+31+...+29)/31"}
  ↓
工具执行 → 观察: 结果=30.2°C
  ↓
LLM思考: "已获得最终答案，可以回复用户。"
  ↓
LLM最终回复: "2024年7月北京平均气温约30.2°C..."
```

### Prompt工程进阶

| 技术 | 说明 | 典型应用 |
|------|------|----------|
| **Zero-shot** | 直接让模型回答（无示例） | 简单问答 |
| **Few-shot** | 提供N个示例作为上下文 | 分类/结构化输出 |
| **CoT (Chain of Thought)** | "让我们一步步思考" + 推理过程示例 | 复杂推理/数学 |
| **Self-Consistency** | 生成多条推理路径，投票选最优答案 | 高可靠性需求 |
| **Tree of Thoughts** | 树状搜索多个推理路径，探索+回溯 | 创意/复杂规划 |
| **Structured Output** | 指定JSON Schema/分类标签强制输出结构 | API集成/数据分析 |

### LLM推理优化（生产部署关键）

| 优化技术 | 说明 | 效果 |
|----------|------|------|
| **KV Cache** | 缓存已生成token的Key/Value张量，避免重复计算 | 推理速度↑3-10x |
| **批量推理 (Batching)** | 同时处理多个请求，填充GPU计算单元 | 吞吐量↑2-5x |
| **量化 (AWQ/GPTQ)** | 4-bit/8-bit量化权重 | 显存↓50-75%，速度↑ |
| **Speculative Decoding** | 小模型草稿 + 大模型验证，减少串行步 | 速度↑2-3x |
| **vLLM PagedAttention** | 虚拟内存管理KV缓存，支持连续批处理 | 吞吐量↑20x |

## 7.3 完整代码示例

### Python：完整RAG实现（LangChain）

```python
"""
依赖: pip install langchain langchain-community langchain-openai faiss-cpu
          pypdf sentence-transformers fastapi uvicorn
"""
from langchain.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.embeddings import HuggingFaceEmbeddings
from langchain.vectorstores import FAISS
from langchain.llms import HuggingFacePipeline
from langchain.chains import RetrievalQA
from langchain.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
import torch

# =============== 1. 文档加载与切分（索引阶段） ===============
print("📄 加载文档...")
loader = PyPDFLoader("docs/your_document.pdf")
documents = loader.load()
print(f"   已加载 {len(documents)} 页")

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=800,    # 每块800字符
    chunk_overlap=100, # 重叠100字符避免上下文断裂
    length_function=len,
)
chunks = text_splitter.split_documents(documents)
print(f"   切分为 {len(chunks)} 块")

# =============== 2. 向量化 + 存储到向量库 ===============
print("🔢 向量化...")
embeddings = HuggingFaceEmbeddings(
    model_name="BAAI/bge-small-zh-v1.5",
    model_kwargs={'device': 'cuda' if torch.cuda.is_available() else 'cpu'},
    encode_kwargs={'normalize_embeddings': True}
)

vectorstore = FAISS.from_documents(chunks, embeddings)
vectorstore.save_local("faiss_index")
print("✅ 向量库已保存到 faiss_index/")

# =============== 3. 构建RAG检索链（在线推理） ===============
print("🤖 构建RAG系统...")
vectorstore = FAISS.load_local("faiss_index", embeddings)
retriever = vectorstore.as_retriever(
    search_type="similarity",
    search_kwargs={"k": 5}  # 检索top-5
)

# 自定义Prompt模板（含Context + 用户问题）
rag_prompt = PromptTemplate.from_template("""
你是一个专业的文档助手。请仅根据提供的上下文回答问题。
如果上下文没有答案，请明确说"根据文档内容无法回答此问题"。

【上下文】
{context}

【用户问题】
{question}

【回答】
""".strip())

# 使用本地LLM或OpenAI API
# 本地部署示例: Llama-2-7B-Chat / Qwen-7B-Chat (用transformers或vLLM)
# API调用示例: from langchain.chat_models import ChatOpenAI
from langchain.chat_models import ChatOpenAI
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0, streaming=True)

# LCEL表达式语言组装RAG链
def format_docs(docs):
    return "\n\n".join(f"[文档{i+1}]\n{doc.page_content}" for i, doc in enumerate(docs))

rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | rag_prompt
    | llm
    | StrOutputParser()
)

# =============== 4. 使用 ===============
print("\n" + "=" * 50)
print("RAG系统已就绪，输入问题开始对话（输入 quit 退出）")
print("=" * 50)

while True:
    question = input("\n你: ").strip()
    if question.lower() in ("quit", "exit", "q"): break
    if not question: continue
    
    print("\n助手:", end=" ", flush=True)
    # 流式输出
    for chunk in rag_chain.stream(question):
        print(chunk, end="", flush=True)
    print()
```

### Java：LangChain4j RAG + Spring Boot

```java
// pom.xml
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-open-ai</artifactId>
    <version>0.28.0</version>
</dependency>
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-embeddings-all-minilm-l6-v2</artifactId>
    <version>0.28.0</version>
</dependency>

// 应用代码
package com.ai.rag;

import dev.langchain4j.data.document.Document;
import dev.langchain4j.data.document.loader.FileSystemDocumentLoader;
import dev.langchain4j.data.document.splitter.DocumentSplitters;
import dev.langchain4j.data.segment.TextSegment;
import dev.langchain4j.model.chat.ChatLanguageModel;
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.model.openai.OpenAiChatModel;
import dev.langchain4j.store.embedding.EmbeddingStoreIngestor;
import dev.langchain4j.store.embedding.inmemory.InMemoryEmbeddingStore;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.*;

import java.util.List;
import java.util.Map;

@RestController
@RequestMapping("/api/rag")
public class RagController {
    
    private final Assistant assistant;
    
    public RagController() {
        // 1. 加载文档
        List<Document> docs = FileSystemDocumentLoader.loadDocuments("./docs/");
        
        // 2. 向量化 + 存储
        EmbeddingModel embeddingModel = new AllMiniLmL6V2EmbeddingModel();
        InMemoryEmbeddingStore<TextSegment> embeddingStore = new InMemoryEmbeddingStore<>();
        EmbeddingStoreIngestor.ingest(docs, embeddingStore, embeddingModel);
        
        // 3. LLM + 检索增强
        ChatLanguageModel llm = OpenAiChatModel.withApiKey(System.getenv("OPENAI_API_KEY"));
        assistant = AiServices.builder(Assistant.class)
            .chatLanguageModel(llm)
            .embeddingStore(embeddingStore)
            .embeddingModel(embeddingModel)
            .chatMemory(MessageWindowChatMemory.withMaxMessages(20))
            .build();
        
        System.out.println("✅ RAG系统初始化完成，文档数: " + docs.size());
    }
    
    @PostMapping("/chat")
    public Map<String, String> chat(@RequestBody Map<String, String> body) {
        return Map.of("answer", assistant.chat(body.getOrDefault("question", "")));
    }
    
    interface Assistant {
        String chat(String userMessage);
    }
    
    public static void main(String[] args) {
        SpringApplication.run(RagController.class, args);
    }
}
```
