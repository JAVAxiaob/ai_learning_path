# 🧮 01 - 数学与Python基础 - 核心知识点与直觉理解

## 一、线性代数 = AI的数学语言

| 知识点 | 数学公式 | 直觉理解 + 在AI中的对应 |
|--------|---------|----------------------|
| **矩阵乘法** | `(AB)_{ij} = Σ_k A_{ik}·B_{kj}` | 🔑 **= 线性变换 + 信息聚合**。Transformer的Q·Kᵀ就是算注意力权重；神经网络的全连接层 Y = XW + b 就是矩阵乘法。**注意：AB ≠ BA 交换律不成立** |
| **转置 / 逆** | `Aᵀ`行列互换；`A⁻¹` 满足 `AA⁻¹ = I` | 转置用来做向量点积（相似度）；逆矩阵用来求线性回归闭式解。实际中很少真的求逆（数值不稳定），用LU分解/梯度下降替代 |
| **特征值/特征向量** | `Av = λv` | 找到"变换后方向原地不动"的向量 → v是主轴，λ是轴的拉伸程度。**PCA主成分分析 = 对协方差矩阵做特征值分解，取前K个最大λ对应的v** |
| **向量点积** | `a·b = |a||b|cosθ` | 🔑 两个向量的"相似度"，越大越相似。**Embedding相似度 = 点积 / cosine**；注意力分数 = Softmax(Q·Kᵀ / √d_k) |
| **张量 Tensor** | 标量(0D)→向量(1D)→矩阵(2D)→3D(RGB图)→4D(Batch图像)→5D(视频) | PyTorch/TensorFlow的基本数据单位。**形状操作 reshape/permute/squeeze 是日常操作，比矩阵运算写的还多** |

> 💡 传统开发结合点：
> - Android `Matrix`类做图像缩放旋转 = 2D矩阵乘法
> - Java 二维数组 → NumPy `ndarray` 的维度概念
> - RecyclerView 列表 = 每个item是向量，整个列表是矩阵

## 二、概率统计 = 处理不确定性

| 知识点 | 公式 | AI中的应用 |
|--------|------|-----------|
| **贝叶斯定理** | `P(A|B) = P(B|A)·P(A) / P(B)` | 先验P(A) + 观测证据 → 后验概率。垃圾邮件分类、朴素贝叶斯的基础 |
| **高斯分布** | `f(x) = (1/√(2π)σ)·exp(-(x-μ)²/2σ²)` | 自然界大量数据服从。权重初始化(He init μ=0,σ=√(2/n))、噪声建模 |
| **Softmax** | `σ(x_i) = exp(x_i) / Σ_j exp(x_j)` | 将任意实数向量→概率分布（和为1）。**多分类问题输出层必用** |
| **交叉熵损失 H(p,q)** | `-Σ_i p_i·log(q_i)` | 🔑 分类问题标准损失函数。**直觉：**当正确类预测概率=0.01时，交叉熵惩罚=-log(0.01)=4.6，而MSE只有(1-0.01)²≈0.98 → **对"错误置信度高"的样本惩罚力度大得多，梯度更稳定** |

> ⚠️ 面试必答：为什么分类用交叉熵不用MSE？
> 1. 交叉熵对错误置信度高的样本梯度更大（收敛快）
> 2. MSE在sigmoid饱和区梯度几乎为0（梯度消失），交叉熵无此问题
> 3. 交叉熵和Softmax的组合求导结果很简洁：`∂L/∂z = ŷ - y`

## 三、梯度下降 = 所有模型优化的核心

**必背公式：**
```
θ_{t+1} = θ_t - η · ∇L(θ_t)
  ↑新参数  ↑旧参数  ↑学习率  ↑损失梯度（指向损失增加最快方向，所以减号反方向）
```

### 优化器对比（面试频率 ⭐⭐⭐⭐⭐）

| 优化器 | 机制 | 特点 |
|-------|------|------|
| SGD | 每个样本/batch算梯度更新 | 简单+噪多有助于跳局部最优 → 实际很少单独用 |
| **SGD+Momentum** | `v = βv + (1-β)∇L ; θ = θ - ηv` | 加惯性，过鞍点快，震荡小 |
| RMSProp | 梯度平方的指数移动平均，自适应学习率 | 稀疏特征场景好（NLP/推荐） |
| **Adam ⭐默认首选** | Momentum（一阶矩）+ RMSProp（二阶矩）+ 偏置校正 | 几乎所有场景默认用这个！调参：lr=1e-3, β1=0.9, β2=0.999 |

### 学习率调度
- **固定学习率**：简单；**Warm-up + 余弦退火** = 2025最佳实践
- 训练初期用小lr(1e-5)跑几百步Warm-up避免不稳定，再升到最大lr，余弦缓慢衰减到最小lr

### ⚠️ 梯度消失 vs 爆炸（深度网络必问）
原因：反向传播链式法则 = 很多偏导数连乘 → 每个<1就指数衰减消失，每个>1就指数增长爆炸
解决方案（背4条）：
1. **ReLU激活**：正区间梯度恒=1 不衰减
2. **残差连接 ResNet**：y = F(x) + x → 梯度多了一条恒等=1的高速路
3. **BatchNorm/LayerNorm**：每一层输出标准化，稳定分布
4. **权重初始化 + 梯度裁剪**：He init / Xavier init；梯度>阈值就clip

## 五、Pandas 数据处理核心

### 特征工程基础Pipeline（面试写代码）
```python
import pandas as pd
import numpy as np

df = pd.read_csv('data.csv')

# 1. 查看缺失值
missing = df.isnull().sum().sort_values(ascending=False)

# 2. 填充缺失值
numeric_cols = df.select_dtypes(include=[np.number]).columns
category_cols = df.select_dtypes(exclude=[np.number]).columns
df[numeric_cols] = df[numeric_cols].fillna(df[numeric_cols].median())  # 中位数填充数值
df[category_cols] = df[category_cols].fillna('Unknown')                # Unknown填充类别

# 3. 类别编码
df = pd.get_dummies(df, columns=category_cols, drop_first=True)        # One-Hot

# 4. 数值归一化 Min-Max [0,1]
for col in numeric_cols:
    mn, mx = df[col].min(), df[col].max()
    if mx > mn: df[col] = (df[col] - mn) / (mx - mn)
```

> 🔑 **`groupby().agg()` vs `groupby().transform()` 必背区别（面试10次9次问）**：
> - `agg()` = **聚合缩减** → 每组输出1行（如每个城市的平均收入），行数变少
> - `transform()` = **广播保持行数** → 每组输出和原来一样多行（如每个用户减去其所在城市平均收入=偏差特征），**行数不变，方便拼回原DataFrame做特征**
