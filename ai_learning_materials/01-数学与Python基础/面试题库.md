# 🎯 01 - 数学与Python基础 - 面试题库（45题含答案）

## 一、基础理论题（25题）

| 题号 | 题目 | 参考答案要点 |
|-----|------|------------|
| 1.1 | 为什么矩阵乘法不满足交换律？ | **空间变换视角**：先旋转再缩放 ≠ 先缩放再旋转，两个操作顺序不同结果不同。从维度看A(m×n)×B(n×p)存在，但BA可能维度不兼容，就算兼容数值也不同。 |
| 1.2 | 特征值/特征向量的意义？PCA为什么用？ | 定义 `Av=λv`：v是变换后"方向不变"的主轴，λ是该轴的拉伸程度。PCA=对协方差矩阵求特征分解，取前K个最大λ对应v=保留数据方差最大的K个投影方向=降维最少信息损失。 |
| 1.3 | ⭐⭐ 交叉熵 vs MSE 做分类损失区别？ (高频) | ①交叉熵对错误置信度高的样本梯度大(MSE梯度在sigmoid饱和区≈0消失)；②交叉熵+Softmax求导结果简洁 ŷ-y，数值稳定。**分类默认交叉熵，回归默认MSE。** |
| 1.4 | 学习率太大/太小有什么问题？ | 太大：在最优点附近震荡→发散/永远不收敛；太小：收敛极慢→陷入局部最优→浪费算力。解决方案：学习率调度（Warm-up + 余弦退火）+ 自适应优化器Adam。 |
| 1.5 | BGD / SGD / Mini-batch GD 对比？ | BGD：全样本算梯度，稳定但慢(O(n) per step)。SGD：1样本，快但噪震荡大。Mini-batch：(32/64/128)平衡速度与稳定性→**工业界99%用这个。** |
| 1.6 | ⭐梯度消失/爆炸原因 + 5个解决方案 | 反向传播=很多偏导数连乘，每个<1指数衰减消失，每个>1指数增长爆炸。✅解：ReLU激活正区间梯度=1；残差连接y=F(x)+x加梯度恒等通路；BN/LN层间标准化；He/Xavier权重初始化；梯度裁剪clip_by_norm。 |
| 1.7 | Adam 相比 SGD 改进在哪？ | Adam=SGD+Momentum(一阶矩m:梯度移动平均，积累惯性过鞍点)+RMSProp(二阶矩v:梯度平方移动平均，每个参数自适应学习率，稀疏特征更友好)+偏置校正(初期m/v偏向0)。**默认首选优化器**。 |
| 1.8 | Softmax 为什么要减去最大值？ | ⭐防**数值溢出**：x=1000时e^1000=∞→nan。softmax(x + c) = softmax(x)数学上严格等价，所以减去每行最大值max(x)所有元素都≤0，e^x≤1不会溢出。 |
| 1.9 | `np.dot` vs `np.matmul` (`@`) | dot：2D=矩阵乘法，1D=点积；但≥3D时行为奇怪（把最后两维相乘其他广播）。matmul（`@`符号）：专门矩阵乘法，**明确处理batch维度（前N-2维广播，最后2维矩阵乘）**→推荐用 `@`。 |
| 1.10 | ⭐`groupby().agg()` vs `transform()` | agg=**聚合缩行**：每组输出1行(如城市平均收入)，行数变少。transform=**保持行数广播**：每组输出和原来一样多（如用户-他所在城市平均收入=偏差特征），方便拼回原df加新特征。 |
| 1.11 | 贝叶斯定理 + 简单应用场景 | `P(A\|B)=P(B\|A)P(A)/P(B)`。垃圾邮件分类：P(垃圾\|邮件正文) ∝ P(邮件正文\|垃圾)·P(垃圾)，用独立特征朴素假设=朴素贝叶斯分类器。 |
| 1.12 | 向量点积和余弦相似度关系 | 点积 = \|a\|\|b\|cosθ；余弦相似度 = 点积 / (\|a\|\|b\|)。余弦相似度**归一化了向量长度的影响，只看方向相似**。推荐场景通常用余弦，避免流行度偏差。 |
| 1.13 | NumPy广播机制规则 | 从后往前比维度：①相等 或 ②一方为1 → 该维广播。否则报错：`operands could not be broadcast together`。好处：省循环，省内存。 |
| 1.14 | 动量Momentum为什么收敛更快？ | 加"惯性"：v = β·v_prev + (1-β)·g。历史梯度持续影响方向：①抑制梯度方向不断变化的震荡（如 ravine 峡谷）②过鞍点/平坦区靠惯性冲过去，不会卡在局部最优点。 |
| 1.15 | 什么是张量？举几个实际维度例子 | 多维数组的推广。标量(0D)=一个数；向量(1D)=[1,2,3]；矩阵(2D)=灰度图；3D=[H,W,C]=RGB彩图/[Seq, Batch, d_model]；4D=[B,H,W,C]=一批图像；5D=[B,T,H,W,C]=视频片段。 |
| 1.16 | One-Hot编码的优缺点 | ✅优：简单，无自然顺序假适合无大小关系类别。❌缺：高基数(如邮编10万类)维度爆炸→稀疏矩阵→模型难训。替代方案：Target Encoding（用目标均值编码，加交叉验证防泄漏）。 |
| 1.17 | Min-Max归一化 vs Z-score标准化 | Min-Max：(x-min)/(max-min)→[0,1]。适用：SVM/KNN/神经网络等对范围敏感算法；缺点：被outlier主导。Z-score：(x-μ)/σ→均值0方差1。适用：逻辑回归/线性SVM等假设正态分布算法。**鲁棒性更好（对异常值不那么敏感）。** |
| 1.18 | PCA 完整步骤（面试手写） | ①数据中心化：x' = x - mean；②协方差矩阵：Σ = (1/n)X'ᵀX'；③特征值分解Σv=λv，选前K个最大λ对应特征向量V_k；④投影：z = X·V_k，得到n×K降维矩阵。 |
| 1.19 | 线性回归最小二乘闭式解？什么情况下用梯度下降？ | 闭式：w = (XᵀX)⁻¹Xᵀy。一次计算得最优，无需迭代。但①O(d³)矩阵求逆慢（d特征数>10000时吃不消）；②XᵀX可能不可逆（多重共线性/特征d>样本n）。→ 大数据/高维用梯度下降。 |
| 1.20 | 逻辑回归为什么叫"回归"却做分类？ | 实际是做**对数几率回归**：ln(p/(1-p)) = wᵀx+b，把线性回归的实数输出→sigmoid压缩到[0,1]当正类概率，p>0.5判正类。建模的是对数几率（回归问题），但用阈值切分做分类。 |
| 1.21 | ⭐Transformer注意力的QKV分别是什么？ | Q=Query(当前词的查询向量)，K=Key(所有词的键向量)，V=Value(所有词的内容向量)。分数 = Softmax(Q·Kᵀ / √d_k) → 每行是"当前词"对"所有词"的注意力权重；加权求和V →输出=提取了上下文相关的新表示。 |
| 1.22 | 为什么注意力要除以 √d_k？ | 当d_k很大时，点积的方差≈d_k →数值很大→Softmax后梯度几乎为0（饱和区）。除以√d_k后，方差变回1→数值稳定，Softmax梯度正常。 |
| 1.23 | L1 vs L2 正则化区别 | L1=λ\|w\|：产生稀疏解（很多w=0）→可做特征选择。L2=λw²：权重平滑分散，不会为0→防过拟合更稳定。数学：L1次梯度在0有间断，L2处处可导易优化。 |
| 1.24 | `df.merge` vs `df.join` vs `pd.concat`？ | merge：**按列键** JOIN（类似SQL JOIN on）支持内/左/右/外。join：**按索引** JOIN，默认索引对齐。concat：**按轴拼接**，axis=0纵向拼多表加行；axis=1横向拼多表加列。 |
| 1.25 | 什么是Training-Serving Skew？怎么防？ | ⭐**线上模型效果差的头号凶手！** 训练端特征处理和推理端不一致→模型输入分布变了→效果暴跌。防：①特征处理Pipeline序列化保存（sklearn的StandardScaler→pickle/dump），Java端加载同一个scaler；②部署前做一次Golden集双向验证（Python训完推理vs Java推理误差≤1e-5）。 |

| P4 | `[B,H,W,C]` NHWC 转 `[B,C,H,W]` NCHW | `x.transpose(0, 3, 1, 2)`；PyTorch默认NCHW，TF/OpenCV读入是NHWC→这个转置日常写。 |
| P5 | NumPy简化版Conv2D（输入3x3核 padding=0 stride=1） | 三重循环：i,j滑窗，`np.sum(input[i:i+3,j:j+3] * kernel)` 存入out[i,j]。 |
| P6 | Pandas 统计每列缺失值数量 → 返回**降序排序**的Series | `df.isnull().sum().sort_values(ascending=False)`。一行写完。 |
| P7 | NumPy 实现标准化 `(x-mean)/std` 指定维度 | 用 `keepdims=True` 保持形状广播：`(x - x.mean(axis=-1, keepdims=True)) / (x.std(axis=-1, keepdims=True) + 1e-8)` + epsilon防除零。 |
| P8 | ⭐纯Python + NumPy 线性回归闭式解 `w=(XᵀX)⁻¹Xᵀy` | `w = np.linalg.inv(X.T @ X) @ (X.T @ y)`；⚠️ 实际推荐 `np.linalg.lstsq`（数值更稳，不真求逆）。 |
| P9 | NumPy算交叉熵损失：ŷ_proba(batch,C) + y_true(batch,) | 取正确类概率：`p = y_pred[np.arange(n), y_true]`；loss = `-np.mean(np.log(np.clip(p,1e-15,1-1e-15)))`，**加clip防log0**。 |
| P10 | ⭐NumPy算余弦相似度矩阵：两个向量集合 A(m,d), B(n,d) → 输出(m,n) 所有两两余弦 | 先单位化 `An = A / np.linalg.norm(A,axis=1,keepdims=True)`，`Bn同理`；余弦 = `An @ Bn.T`（单位向量点积=余弦）。一行写。 |
| P11 | 实现 `@timer` 装饰器打印函数耗时 | `time.time()` 前后相减；**必须用 `@functools.wraps(func)` 保留原函数名和文档，不然装饰后函数名变成wrapper**。 |
| P12 | Python 生成器 `read_big_file()` 批量读10GB日志不爆内存 | `for line in f:`（Python读文件是迭代器）；每攒满1000行就 `yield batch_lines` → 一次只占一批内存。 |
| P13 | 手写 LRU Cache（双链表+哈希，大厂必问） | 两个核心：`cache={key:Node}` O(1)查找；**双向链表**维护最近访问顺序。get命中→删node移到head；put超容量→删tail.prev。 |
| P14 | NumPy 对数组做 Top-K 索引（如分类模型取置信度前3类） | `np.argsort(-probs, axis=1)[:, :3]`（-argsort降序，或用`np.argpartition`更快O(n)不用全排序）。 |
| P15 | Pandas Target Encoding：类别列→对应目标均值编码，防泄漏要5折CV | 用 `sklearn.model_selection.KFold`，每一折：训练集算groupby均值→映射到验证集。绝对不能用全量数据算再映射回自己（数据泄漏！）。 |
| P16 | NumPy 实现滑动窗口平均（1D） | 核=np.ones(window)/window；卷积 `np.convolve(arr,核,mode='valid')`。mode='valid' 不要填充，'same'输出等长。 |
| P17 | Python 深拷贝 vs 浅拷贝 | `copy.copy()` 浅=只拷贝一层引用，嵌套list里面还共享；`copy.deepcopy()` 深=递归拷贝所有对象，嵌套对象也独立。 |
| P18 | Pandas 去除重复行 + 按某列去重保留最后出现的 | `df.drop_duplicates(subset=['col1','col2'], keep='last')`；keep='first'(默认)/'last'/False全删。 |
| P19 | NumPy 布尔索引 + 条件赋值 | `arr[arr < 0] = 0` 截断负值；复杂条件 `arr[(arr>5) & (arr<10)]`；注意 **&、\| 代替 and、or（因为逐元素非短路逻辑），每个条件加括号。** |
