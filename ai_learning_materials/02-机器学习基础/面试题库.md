## 第一组：基础概念（10题）

### 1. 什么是偏差(bias)和方差(variance)？过拟合和欠拟合和它们是什么关系？（⭐⭐⭐⭐⭐ 每面必问）
**答**：
- **偏差Bias** = 模型预测值和真实值的「平均差距」= 模型本身的准度。高偏差 = 模型太简单，学不到规律 → **欠拟合 Underfitting**
- **方差Variance** = 多次训练不同数据集，模型预测结果的「波动程度」= 模型的稳定性。高方差 = 模型对数据集太敏感，学到了训练集的噪声 → **过拟合 Overfitting**

> 直观比喻：
> 欠拟合 = 闭卷考试瞎蒙（什么都没学会）；**过拟合 = 把历年真题答案全背下来（考新题就崩）；好模型 = 真的学会了知识点 + 新题也能做对

**解决过拟合（高方差）的5个方法：
① 增加数据量；② 正则化（L1/L2/Dropout）；③ 降低模型复杂度（减少层数/决策树剪枝；④ 集成学习Bagging/RF；⑤ 早停 Early Stopping

**解决欠拟合（高偏差）的5个方法：
① 增加模型复杂度（换更深的树/加层）；② 减少正则化强度；③ 增加特征维度做更好的特征工程；④ 延长训练时间；⑤ Boosting集成

### 2. 什么是 L1 L2 正则化？区别是什么？为什么 L1 稀疏 L2 平滑？
**答**：损失函数加罚项防止权重w过大→限制模型复杂度：
- L1 = λ·Σ|w|   → Laplace 先验，**解稀疏**（大部分w变0，做特征选择）。原因：菱形约束方形解常在角上=某些w=0
- L2 = λ·Σw²   → Gaussian 先验，**解平滑**（w都很小但不是0），稳定抗共线。原因：圆形约束方形解常在边上=w都很小

### 3. 为什么要做特征标准化/归一化？哪些模型需要？哪些不需要？
**需要标准化模型**（⭐面试高频）：
| 需要（距离/梯度相关） | 不需要（树形结构） |
|-----------------|--------------|
| 线性回归、逻辑回归、SVM、KNN、K-Means、PCA、LDA、神经网络 | 决策树、随机森林、XGBoost/LightGBM/CatBoost |
| **原因**：梯度下降收敛快；距离计算公平，不会被大数值特征统治 | **原因**：分裂只看「相对排序」和「分裂前后纯度变化」，跟绝对数值无关 |

### 4. K折交叉验证(KFold) vs 分层KFold(StratifiedKFold) vs 时间序列切分
- **KFold**：训练集随机切成K份，每份依次当验证集（适合**均匀数据集**
- **StratifiedKFold** ⭐默认用这个：**按类别比例分层切分**，每折正负比例 = 全量比例。适合**样本不平衡**（欺诈检测/癌症筛查）
- **TimeSeriesSplit**：时间序列数据**绝对不能随机打乱**！必须：训练集始终在验证集的过去时间段（防止未来信息泄漏！）

### 5. 怎么处理样本不平衡？（9:1 不平衡数据）⭐⭐⭐⭐
**答**（按优先级从高到低排列）：
1. ⭐**第一步！先换评估指标：不看Accuracy，只用 AUC / Recall / F1
2. **数据层面 采样**：
   - 欠采样(Under)：删多数类样本 → 丢信息；用 EasyEnsemble 多组欠采样+集成
   - 过采样(Over)：复制少数类 → 容易过拟合；✅ **SMOTE 合成新的少数类样本（K近邻插值）
3. **算法层面**：XGBoost/LightGBM 的 `scale_pos_weight` 给少数类加大损失权重；class_weight='balanced'
4. 检测/异常问题直接换思路：**一分类 SVM / Isolation Forest** 当成异常检测做

### 6. 为什么XGBoost用二阶泰勒展开？为什么用什么好处？
**答**：损失函数用二阶泰勒展开近似 $L(y, F) ≈ g·Δ + ½·h·Δ²：
1. **精度更高**：二阶近似比一阶（GBDT只用梯度）更接近真实损失曲面，每一步走的更准→收敛更快
2. **自定义损失友好**：只要损失二阶可导就能用（比如MAE也能用！MSE以外的自定义损失函数直接套公式）
3. **闭式解叶子权重**：w = -Σg / (Σh + λ)  一步求导=0直接求出来了，不用再像GBDT那样线性搜索

### 8. 随机森林 RF 为什么抗过拟合？
核心 3 随机性 = 方差抵消：
① Bootstrap 样本随机（有放回抽样，每棵树训练样本不完全一样，树不一样）

## 第三组：评估指标（10题）

### 10. AUC 到底是什么？怎么理解？AUC计算公式？
**AUC = Area Under ROC Curve = ROC曲线下的面积，值域[0.5,1]。
**物理意义**：随机抽1个正样本 + 1个负样本，正样本预测分数>负样本预测分数」的概率！
- AUC = 0.7 模型完全瞎猜；AUC = 1 完美排序

AUC优点（面试答这两条就够了）：
✅ 不受阈值影响（不管阈值多少都能用一个指标全面评估）
✅ 抗样本不平衡（1:99不平衡依然有效）

**AUC 缺点**：AUC高不代表业务好，关心排序时用AUC；关心精确率看P/R

### 11. ROC 曲线怎么画？FPR TPR 含义？
X轴 = FPR = FP/(FP+TN) =「所有真负样本里，被错判成正的比例（误诊率）。
Y轴 = TPR = Recall = TP/(TP+FN) =「所有真正类里被抓到的比例。
画法：从高→低遍历所有可能分类阈值，每个阈值算出一个点连起来就是ROC曲线→线下面积就是AUC

### 12. 什么时候用F1？什么时候用MSE？什么时候用AUC？
- P和R同样重要时 → **F1**（调和平均。不平衡+业务场景：搜索推荐既不能漏太多也不能错太多
- 只要排序对不对 → **AUC**（模型整体排序能力，点击率预估排序好就行
- 数值预测数值差多少要精确 → **MSE**（回归对大误差惩罚重，房价预估

### 13. SVM 为什么叫最大间隔？什么是支持向量？
最大间隔 = 正负类离超平面最近的样本点（超平面只由这几个点决定，跟其他样本点无关，其他样本不影响超平面）= 支持向量Support Vectors。好处：**抗噪声泛化能力好**

### 14. 核函数怎么选？
```
特征多维度高样本少 → 线性核（文本分类标准选线性就够了快+不过拟合）
特征少维度低样本中 → RBF 高斯核先
样本多 → 深度学习
不知道选什么 → **线性核先试RBF
```

### 15. K-Means 怎么确定K？K-means 步骤？
步骤：①随机选K个初始质心→②每个样本归到最近质心→③重新算每类质心是类内均值→重复②③直到质心不变。

怎么选K：
1. **肘部法则**：画K从2到20，每个K对应的SSE（每个样本到质心距离平方和），突然下降变缓那个拐点就是最佳K
2. **轮廓系数 Silhouette Score：越接近1越好（类内紧凑+类间分离

### 代码题1：自己从头写信息熵信息增益（决策树）
```python
import numpy as np
def entropy(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / len(y)
    return -np.sum(p * np.log2(p + 1e-9))  # +1e-9防log(0)

def info_gain(X_col, y, threshold):
    """X_col 是一个特征列，按threshold切分，信息增益"""
    mask = X_col <= threshold
    y_left, y_right = y[mask], y[~mask]
    if len(y_left) == 0 or len(y_right) == 0: return 0
    n = len(y)
    return entropy(y) - (len(y_left)/n * entropy(y_left) + len(y_right)/n * entropy(y_right))

# 测试
y = np.array([1]*6 + [0]*6)
print(f"不切Entropy: {entropy(y):.3f}")
X_col = np.array([1,1,1,2,2,3, 4,5,5,6,7,7])
for t in [2.5, 3.5, 4.5]:
    print(f"阈值{t}信息增益={info_gain(X_col, y, t):.4f}")
```

### 代码题2：手撕AUC计算（不用sklearn，2种方法）
```python
# 方法一：物理意义法：所有正负样本对，正分>负分的比例。时间O(n²)面试写这个简单
def auc_bruteforce(y_true, y_score):
    pos_scores = y_score[y_true==1]
    neg_scores = y_score[y_true==0]
    n_pos, n_neg = len(pos_scores), len(neg_scores)
    if n_pos == 0 or n_neg == 0: return 0.5
    cnt = sum(p > n for p in pos_scores for n in neg_scores)
    tie = sum(p == n for p in pos_scores for n in neg_scores) * 0.5
    return (cnt + tie) / (n_pos * n_neg)

# 方法二：工业级排序法 O(n log n)。面试解释原理：排序后正样本的秩(Rank)求和法
from sklearn.metrics import roc_auc_score
y = np.array([1,1,0,0,1,0])
scores = np.array([0.9, 0.8, 0.3, 0.1, 0.7, 0.5])
print(f"sklearn AUC: {roc_auc_score(y, scores):.3f}")
print(f"手撕 AUC:   {auc_bruteforce(y, scores):.3f}")
```

### 代码题3：手撕逻辑回归 + 梯度下降
```python
def sigmoid(z): return 1 / (1 + np.exp(-np.clip(z, -500, 500)))
# 训练
def logistic_regression_train(X, y, lr=0.01, epochs=5000):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        ŷ = sigmoid(X @ w + b)
        # 交叉熵梯度
        err = ŷ - y
        dw = (X.T @ err) / n   # 梯度公式正好是 X^T (ŷ-y) / n （和MSE梯度公式神似！
        db = err.mean()
        w, b = w - lr*dw, b - lr*db
    return w, b
# 推理
def predict_proba(X, w, b): return sigmoid(X @ w + b)
```
