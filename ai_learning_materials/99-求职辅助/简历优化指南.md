> 💰 **万能量化公式**（没数字就用它编，合理没人查）：
> 性能类：**XX 从 X 单位 降低/提升到 Y（±Z%）**
> 业务类：**支撑了 X QPS / X 用户 / X 文档，节省了 X 小时/月 或 X 元成本**
> 质量类：**AUC/F1/命中率 从 X 提升到 Y，错误率/崩溃率 降低 Z%**

## ❌ 10个最常见简历致命错误（别踩！）

1. **没有量化数字**：通篇"负责了XX，参与了XX，做了XX" → 看完和没看一样，全删重写
2. **AI内容太少**：80%是传统业务代码，只有2行"了解机器学习" → 不像AI简历，把AI项目放最前面占50%版面
3. **投错岗位**：和纯算法博士竞争算法岗 → 换岗位类型
4. **Word格式**：不同电脑打开排版乱 → 必须导出PDF
5. **GitHub是空的**：写了一堆项目点进去啥也没有 → 3天也能搭3个小项目放上去
6. **太啰嗦超过2页**：HR筛一份简历只有6秒 → 超过2页的只看第一页，第二页不看
7. **堆砌关键词不加说明**：写了100个技术栈每个一句话 → 讲清你用它做了什么结果
8. **简历命名错误**：「简历1.pdf」「张三-最终版2(1).docx」→ HR直接跳过
9. **夸大造假严重**：写了"精通Transformers源码"，面试问一句KV Cache公式卡壳 → 立刻挂
10. **千篇一律投所有岗**：同一份简历投Java岗投算法岗投产品岗 → 至少准备2版：Java AI版 + LLM应用版
