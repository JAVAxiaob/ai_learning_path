#### 1. ⭐⭐⭐⭐⭐ 两数之和（LeetCode 1）
**题目**：数组中找两个数和 = target，返回下标。O(n)
```python
def two_sum(nums, target):
    seen = {}  # val -> idx
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target-x], i]
        seen[x] = i
    return []
```
**扩展：三数之和 = 排序+双指针O(n²)。

#### 2. ⭐⭐⭐⭐ 二分查找（LC34 34 35 704）标准模板（面试写这个没有任何Bug版
```python
# ⭐ 万能二分模板（左右闭区间版
def binary_search(nums, target):
    l, r = 0, len(nums) - 1  # 双闭区间 [l, r]
    while l <= r:           # 注意是 <= (最后一个元素也要检查！
        mid = (l + r) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            l = mid + 1   # 右半区找 [mid+1, r]
        else:
            r = mid - 1   # 左半区找 [l, mid-1]
    return -1  # 没找到
```
> 记住**闭区间 l<=r + mid±1，就不会死循环，所有二分题直接套。

#### 3. ⭐⭐⭐⭐ 最大子数组和 Kadane 算法（LC 53）动态规划简单）
```python
def maxSubArray(nums):
    # dp[i] 以i结尾的最大子数组和 = max(nums[i] 自己或者 还是dp[i-1]+nums[i])
    ans = cur = nums[0]
    for x in nums[1:]:
        cur = max(x, cur + x)   # 要么自己重开要么连前面
        ans = max(ans, cur)      # 全局最优打擂台
    return ans
```

```python
def lengthOfLongestSubstring(s: str) -> int:
    window = {}
    l = ans = 0
    for r, ch in enumerate(s):
        if ch in window and window[ch] >= l:
            l = window[ch] + 1    # 左边界收缩到重复字符右边一位
        window[ch] = r
        ans = max(ans, r - l + 1)
    return ans
```

```python
def isValid(s):
    stack, m = [], {')':'(', ']':'[', '}':'{'}
    for c in s:
        if c in m.values(): stack.append(c)
        elif not stack or stack.pop() != m[c]: return False
    return not stack
```

#### 17. ⭐⭐⭐ SQL 第二高工资 / 第N高
```sql
-- 写法1：LIMIT + OFFSET（最简单
SELECT DISTINCT salary AS SecondHighestSalary
FROM employee ORDER BY salary DESC
LIMIT 1 OFFSET 1;

-- 写法2窗口函数
SELECT MAX(salary) SecondHighestSalary
FROM (SELECT salary, DENSE_RANK() OVER(ORDER BY salary DESC) rk FROM employee) t
WHERE rk = 2;
```

#### 18. ⭐⭐⭐ SQL 连续3天登录的用户
```sql
-- 行号差值法（排序减去 ROW_NUMBER 连续 = 同组
SELECT DISTINCT user_id, MIN(dt), COUNT(*) cnt FROM (
  SELECT user_id, dt,
         DATE_SUB(dt, INTERVAL ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY dt) DAY) grp
  FROM login_log
) t GROUP BY user_id, grp
HAVING COUNT(*) >= 3;
```

### M3. ⭐⭐⭐⭐ 手撸 K-Means 聚类
```python
def kmeans(X, k=3, max_iter=100):
    # 1. 随机k个质心（为了可复现固定seed42）
    rng = np.random.RandomState(42)
    centroids = X[rng.choice(len(X), k, replace=False)]

    for it in range(max_iter):
        # 2. 每个样本到最近质心: 分配 labels
        dists = np.linalg.norm(X[:, None] - centroids, axis=2)  # n×k
        labels = dists.argmin(axis=1)
        # 3. 更新质心 = 每类均值
        new_centroids = np.array([X[labels==j].mean(axis=0) for j in range(k) if np.any(labels==j) else centroids[j]])
        if np.allclose(centroids, new_centroids): break
        centroids = new_centroids
    return labels, centroids
```

```python
def knn_predict(X_train, y_train, X_test, k=5, regression=False):
    dists = -2 * X_test @ X_train.T + (X_test**2)[:,None])
    idx = np.argpartition(dists, k, axis=1)[:, :k]  # top-k
    k_labels = y_train[idx]
    return k_labels.mean(axis=1) if regression else \
           np.apply_along_axis(lambda x: np.bincount(x).argmax(), 1, k_labels)
```

7. **Python/Java** 语法尽量少用奇技淫巧，写可读性好懂优先
