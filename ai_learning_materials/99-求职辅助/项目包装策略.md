### 指标编造合理参考区间（别太夸张一眼假）

| 优化类型 | 合理提升范围 | 例子 |
|--------|------------|-----|
| **准确率/命中率类** | 提升 15~45% 绝对值 | 欺诈捕获 68→92% (+24%) |
| **性能延迟** | 优化 50~85% 相对值 | 推理延迟 240→70ms (-71%) |
| **成本/人力** | 节省 40~80% | 人工审核 -70% |
| **用户指标 CTR/点击率** | 相对提升 20~60% | 推送 CTR 1.2→3.1% (+158% 相对) |
| **QPS/吞吐量** | 2~10 倍 | QPS 500→3500 (7×) |
| **用户体验指标 NPS/满意度** | 绝对 8~20 分 | NPS 32→50 (+18) |

> ⚠️ 反例（一开口就露馅）：

### 🥇 推荐项目 1：「企业知识库 RAG 问答系统」⭐⭐⭐⭐⭐ 面试出现率最高

**技术栈（根据你原背景选）**：
- Java 背景：Spring Boot 3 + Spring AI + Qdrant + PgVector + Vue
- Python 背景：LangChain + LlamaIndex + FastAPI + Chroma
- 前端背景：Vue 3 + 流式 SSE + Markdown 渲染 + 代码高亮
- 全栈组合：**推荐！** 前后端一起做，瞬间完整度拉满

**项目必须包含的 6 个亮点（写 GitHub README + 简历）**：
1. **文档格式**：4 种以上格式（PDF/Word/Markdown/HTML）自动解析
2. **Advanced RAG**：至少 3 层升级（BM25+向量混合检索、Reranker 精排、查询改写、语义切块）
3. **多 LLM 适配层**：一键切换通义/文心/OpenAI/本地 Llama，供应商零耦合
4. **引用溯源**：答案标注来源文件页码，点击跳转到 PDF 对应页
5. **流式 SSE**：打字机输出，首字节 < 300ms，答案质量看板
6. **SLA 指标**：**RAGAS Faithfulness > 90%，Top3 命中率 > 85%，P95 < 1s**

**简历写法**：
> 【项目】企业智能知识库 RAG 系统（个人开源，GitHub 280⭐）
> - SentenceWindow 语义切块 + BM25 向量 RRF 融合检索 + bge-reranker-v2-m3 精排（50→4）+ MultiQuery 多查询改写

## ⚠️ 包装的 4 条安全红线（别越线，不然面试秒挂）

1. ✅ **原理必须真的懂**：你写的每个模型/算法/架构，面试问你 3 个为什么必须答出来。例如写了XGBoost必须能说5个优化点、写了RAG必须能说RAG完整链路+7层升级
2. ❌ **别写你调不了参的内容**：写了"微调Llama3 70B"，面试官问你多少卡训了多久batch多少答不上 = 直接挂
3. ✅ **数字可以合理放大，但别瞎编**：真实提升20%你写28%没问题，但20%写80%就太假了
4. ✅ **宁可写2个深入的项目，也别写5个浅的**：面试官一定会挑一个最深挖，你只要有1个能讲15分钟的深入AI项目，就胜过8个蜻蜓点水的"参与了XX"
